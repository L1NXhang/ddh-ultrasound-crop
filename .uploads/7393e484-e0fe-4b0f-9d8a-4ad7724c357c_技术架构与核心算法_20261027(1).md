```
原始截图

  │

  │
  ├─ ④ 1×1 卷积降维 + ROIAlign → 64×24×16

```

## 1. 问题定义

### 1.1 为什么需要裁剪

婴儿髋关节超声用 **Graf 法**评估，要在标准切面上测 **α 角**和 **β 角**。
但超声仪器导出的截图里除了成像区，还带：

- 设备界面（机型、探头频率、增益、深度参数）
- 右侧深度标尺
- 左下角体位示意图
- 四周黑边

这些都会干扰后续测量，所以**必须先裁出纯成像区**。

### 1.2 为什么先裁上边界

Graf 法要求图像上方包含**髂骨下缘**、**骨性髋臼顶**、**盂唇**等结构，最外层还有**大转子**。
这些结构共同构成"这是不是标准切面"的判断依据。

> **临床依据（华西医院超声科老师确认）**：
> 上边界区域里的大转子是确定切面标准的重要标志，**不应该被收紧裁掉**。

下边界则不能裁太高，否则会切掉股骨头所在的圆形区域。

### 1.3 任务化

给定窗口高度 H 和裁剪线位置，问题可以写成：

```
网络输出：r = (r_top, r_bot)，其中 0 ≤ r_top < r_bot ≤ 1
换算像素：y_top = y0 + r_top · H
          y_bot = y0 + r_bot · H
```

**难点**：边界没有绝对真值，不同标注人对"该裁到哪"的理解不同。

## 2. 基础概念（看懂后面的前提）

### 2.1 卷积（Convolution）

卷积核在图像上滑动，每个位置做**加权求和**：

```
y[i, j] = Σ_m Σ_n  x[i+m, j+n] · w[m, n] + b
```

- **3×3 卷积**：看一个 3×3 的邻域，提取局部纹理
- **7×7 卷积**：看更大范围，通常是网络第一层
- **stride=2**：每次滑 2 格，输出尺寸减半（降采样）
- **1×1 卷积**：不改变分辨率，只改通道数（降维/升维）

**输出尺寸公式**（padding=p, stride=s, kernel=k）：

```
H_out = floor((H_in + 2p − k) / s) + 1
```

例：输入 384，conv1 用 k=7, s=2, p=3 → `(384+6−7)/2 + 1 = 192`

### 2.2 批量归一化（Batch Normalization, BN）

**问题**：网络里每层输出分布随训练漂移，导致后面的层难以适应。

**做法**：对每个通道，在一个 batch 内标准化，再学习两个参数 γ、β 恢复表达能力：

```
μ_B   = (1/m) Σ x_i                    ← batch 均值
σ²_B  = (1/m) Σ (x_i − μ_B)²           ← batch 方差
x̂_i   = (x_i − μ_B) / √(σ²_B + ε)      ← 标准化
y_i   = γ · x̂_i + β                    ← 缩放平移（可学习）
```

**好处**：训练更稳、可以用更大的学习率、对初始化不敏感。

**我们的特殊处理**：训练时把 ResNet 里的 BN **冻结成推理模式**（用预训练的 running stats）。

```python
def train(self, mode=True):
    super().train(mode)
    # Freeze ImageNet BN running statistics for small correlated mini-batches.
    for m in self.backbone.modules():
        if isinstance(m, nn.BatchNorm2d):
            m.eval()
```

原因：batch 只有 8，而且同一批图相关性很强（同一患者相邻帧），
用 mini-batch 统计量会抖得厉害。

### 2.3 输入归一化（ImageNet 标准化）

预训练模型是在 ImageNet 上训练的，输入必须按同样的方式预处理：

```
x_normalized = (x/255 − μ) / σ

μ = (0.485, 0.456, 0.406)     ← ImageNet 三通道均值
σ = (0.229, 0.224, 0.225)     ← ImageNet 三通道标准差
```

代码：

```python
x = (x - torch.tensor([.485,.456,.406])[:,None,None]) \
  / torch.tensor([.229,.224,.225])[:,None,None]
```

**为什么必须做**：不做的话输入分布和预训练时差太多，迁移学习效果大打折扣。

### 2.4 Softmax

把一组任意实数变成**概率分布**（每个 ≥ 0，加起来 = 1）：

```
softmax(z)_i = exp(z_i) / Σ_j exp(z_j)
```

**性质**：

- 输出范围 (0, 1)
- 单调：z_i 越大，输出越大
- 对整体平移不变：`softmax(z + c) = softmax(z)`

**我们的用法**（关键）：不是直接取最大类，而是**累积求和**得到坐标。

```python
def ordered(z):
    # epsilon remains positive even if softmax underflows.
    p = (1-3e-4) * z.float().softmax(-1) + 1e-4
    return torch.stack((p[...,0], p[...,0] + p[...,1]), -1)
```

细节：加了 `1e-4` 下限，防止 softmax 下溢出成 0 时梯度消失。

### 2.5 残差连接（Residual Connection）

**问题**：网络越深越难训练。不是过拟合，是**退化问题**——梯度传不回浅层。

**ResNet 的解法**：

```
普通块：  y = F(x)
残差块：  y = F(x) + x        ← 加一条恒等捷径（identity shortcut）
```

网络只需要学**残差** F(x) = y − x，而不是完整映射。

**为什么管用**：

- 反向传播时，梯度可以沿捷径直接传回浅层（`∂y/∂x = ∂F/∂x + 1`，那个 +1 保证梯度不为 0）
- 学"什么都不做"只需 F(x)=0，比学恒等映射容易

ResNet-18 的基本块叫 **BasicBlock**，由两个 3×3 卷积组成：

```
x ─→ Conv3×3 ─→ BN ─→ ReLU ─→ Conv3×3 ─→ BN ─→ (+) ─→ ReLU ─→ y
 └────────────────── identity ──────────────────┘
```

### 2.6 ROIAlign

**问题**：letterbox 时我们补了黑边，那些黑边不该参与计算。
而且不同图的长宽比不同，补边位置也不同。

**做法**：把"真实内容区域"（ROI）从特征图上**双线性采样**成固定尺寸网格：

```
G[c, i, j] = Σ_{s,t} F[c, s, t] · B(s − x_i) · B(t − y_j)
```

- `B(·)` 是双线性插值核
- `(x_i, y_j)` 是第 (i,j) 个采样点在特征图上的连续坐标
- 输出固定 24×16

**为什么不用 RoIPool**：RoIPool 有量化取整，会有像素级错位；ROIAlign 用浮点坐标双线性插值，无量化误差。

**我们的参数**：`spatial_scale = 1/16`（因为输入 384 → layer3 是 24，正好 1/16）。

## 3. 整体架构

### 3.1 为什么分两阶段

这两件事性质完全不同：

| 阶段 | 问题性质 | 解法 | 是否需要训练 |
|---|---|---|---|
| ① 找成像窗口 | **几何问题**（黑边在哪、亮界面在哪）| 规则算法 | ❌ 不需要 |
| ② 定上下边界 | **语义问题**（该保留哪些解剖结构）| 神经网络 | ✅ 需要 |

**分开的好处**：

- 失败模式不同，出问题能定位是哪一步的锅
- 规则算法可解释、跨设备稳、无训练数据依赖
- 网络只在窗口内部工作，输入尺寸天然统一

**代价**：窗口一旦错，后面全错。所以窗口算法要做到接近 100%。

### 3.2 代码骨架

```python
@torch.no_grad()
def pipeline(row, root, wm, bm, bmeta, device, ...):
    im = image_for(row, root)
    box, reason = select_window(wm([to_tensor(im)])[0], *im.size, threshold=...)
    if reason:
        return {'status': reason, 'box': None}
    x, roi = letterbox(im.crop(tuple(box)), bmeta['size'])
    o = mc_crop(bm, x[None], roi[None], samples=16)
    ...
```

## 4. 阶段一：成像窗口定位（规则几何算法）

代码：`tools/detect_window.py`（321 行，纯 numpy + PIL，无深度学习依赖）

### 4.1 核心判据：不是亮度，是「非纯黑占比」

实测发现：

| 区域 | 像素值 | 非纯黑占比 |
|---|---|---|
| 黑边 | 恒为 0 | **0.000** |
| 成像区深部（最暗处）| 均值接近 0 | **0.36 ~ 0.88** |

所以判据用 **`像素 > 2/255` 算"非纯黑"**——黑白分得极干净。

**为什么不用亮度阈值 / 局部标准差**：成像区内部有大片无回声暗区（均值和黑边一样低），
亮度阈值会把它们判成黑边。二值占比判据对"暗但非纯黑"更鲁棒。

### 4.2 六步流程

#### 第 1 步：内容掩膜

```
像素级：  a > 2                      → 非纯黑
块级：    4×4 块内非纯黑占比 > 0.05  → 该块算内容
```

**关键细节**：必须**先做像素级判定，再聚合到块**，不能先缩放。
因为缩放会把暗区的稀疏斑点平均掉，导致深部内容被误判成黑边。

#### 第 2 步：水平开运算（先）

```python
def open_x(m, r=1):
    """一个块必须在左右各 r 个块内都连续存在，才保留。"""
```

作用：移除 **1~2 块宽的竖细结构**——深度标尺刻度点、TGC 指示条。

**必须在闭运算之前**。如果先闭运算，这些稀疏点会被膨胀成横贯的桥，
把成像区和右侧界面连成一整块，之后再也开不掉。

#### 第 3 步：闭运算（后）

```
y = erode(dilate(m, r=2), r=2)     # 先膨胀再腐蚀
```

作用：填补小块空洞，把碎片连通成整体。

#### 第 4 步：取最大连通域 → 粗框

两遍扫描 + 并查集（union-find）标记连通域，取面积最大的，外接框 ×4 还原到原图坐标。

依据：成像区面积远大于任何界面元素。

#### 第 5 步：左右边界 —— 黑走廊 + 像素级吸附

所有设备的共同结构：

```
成像内容  →  一条黑走廊（窗外）  →  才是界面元素
```

算法：

```
1. 从内容内部（最密的一列）向外扫
2. 遇到连续 ≥2 列占用率 < 0.35 → 判定进走廊
3. 走廊起点 = 粗边界
4. 在 ±12 px 邻域内找梯度最大处，像素级吸附
```

**先做 3 列中值滤波**：走廊里常夹着标尺短横这类单列亮点，会打断"连续低列"计数。

**为什么不用静态阈值分开内容和 TGC 条**：
老设备窗口右缘本身是渐隐的（占用率 0.36~0.57），与 TGC 条（0.37）**数值完全重叠**，
任何静态阈值都分不开。走廊法把界面元素挡在外面。

#### 第 6 步：上下边界 —— 从外向内扫

```
从粗框边缘向内扫，取第一条「非纯黑占比 > 0.20」的行
```

**方向很重要**：必须从外向内。
窗口底部有一条很暗的带（行灰度 0.6~7.8），从内向外游走会被截断；
而窗外的文字行占用率只有 0.03~0.08，低于 0.20 不会被误选。

### 4.3 拒识标记

| 判据 | flag |
|---|---|
| 内容面积 < 5% 或 > 95% | `area_too_small` / `area_too_large` |
| 第二大连通域 > 最大域 25% | `multiple_blocks`（拼图/双屏）|
| 贴图像边界 | `touches_border` |
| 窗口外还有一整片实心内容（占用率>0.5 且连续 5 块）| `content_beyond_*` |

最后一条是**事后检查**，只加标记不改边界，所以不影响已验证的精度。

|---|---|---|
| `T_NONBLACK` | 2 | 大于它就不算纯黑 |

| `MIN_AREA / MAX_AREA` | 0.05 / 0.95 | 面积占比上下限 |

## 5. 阶段二：CropNet 边界预测

代码：`ddh_v2.py` 的 `CropNet` 类

### 5.1 输入预处理：letterbox

**问题**：窗口裁剪出来的图长宽比悬殊，但网络需要固定 384×384。

**如果直接拉伸**：解剖结构会变形，边界位置就错了。

**letterbox 做法**：等比缩放 + 居中补黑。

```python
def letterbox(im, size=384, augment=False):
    im = im.convert('L').convert('RGB')
    if augment:
        im = ImageEnhance.Brightness(im).enhance(random.uniform(.9, 1.1))
        im = ImageEnhance.Contrast(im).enhance(random.uniform(.9, 1.1))
        if random.random() < .5:
            im = im.transpose(Image.Transpose.FLIP_LEFT_RIGHT)
    w, h = im.size
    s = min(size/w, size/h)              # 等比缩放因子
    nw, nh = max(1, round(w*s)), max(1, round(h*s))
    px, py = (size-nw)//2, (size-nh)//2  # 居中补黑偏移
    canvas = Image.new('RGB', (size, size))
    canvas.paste(im.resize((nw, nh), Image.Resampling.BILINEAR), (px, py))
    x = to_tensor(canvas)
    if augment:
        x = (x + torch.randn_like(x) * .01 * x).clamp(0, 1)   # 高斯噪声
    # ImageNet 归一化
    x = (x - torch.tensor([.485,.456,.406])[:,None,None]) \
      / torch.tensor([.229,.224,.225])[:,None,None]
    return x, torch.tensor([px, py, px+nw, py+nh], dtype=torch.float32)
```

**返回两个值**：

- `x`：3×384×384 归一化后的张量
- `roi`：`[px, py, px+nw, py+nh]` —— 真实内容在 384×384 里的位置，给 ROIAlign 用

### 5.2 ResNet-18 主干 —— 为什么只取到 layer3

ResNet-18 的五级结构（输入 384×384）：

| 层 | 输出 | 说明 |
|---|---|---|
| `conv1 7×7/2` | 64×192×192 | 大步长快速降分辨率 |
| `maxpool 3×3/2` | 64×96×96 | 再降一半 |
| `layer1 ×2` (BasicBlock) | 64×96×96 | 保持分辨率 |
| `layer2 ×2` | 128×48×48 | 降一半 |
| **`layer3 ×2`** | **256×24×24** | **← 我们取这里** |
| `layer4 ×2` | 512×12×12 | 语义最强但太粗 |
| `avgpool` | 512 | 全局池化 |

**核心权衡**：

> 我们要定位的是"第几行"。
> `layer4` 只有 **12×12**，纵向 12 格，一格代表 32 个像素——太粗，边界会跳。
> `layer3` 是 **24×24**，纵向 24 格，一格 16 像素，精度够用，而且已有一定抽象能力。
>
> **再深一层牺牲分辨率，再浅一层没有足够语义。24×24 是折中点。**

代码：

```python
def forward(self, x, roi):
    b = self.backbone
    x = b.maxpool(b.relu(b.bn1(b.conv1(x))))
    x = b.layer1(x)
    x = b.layer2(x)
    c3 = b.layer3(x)              # ← 用于边界预测
    c4 = b.layer4(c3)
    embed = b.avgpool(c4).flatten(1)   # ← 512 维，用于 quality 分支
    ...
```

### 5.3 1×1 投影 + ROIAlign

```python
self.project = nn.Conv2d(256, 64, 1)     # 256 → 64 通道，降维省算力

boxes = torch.cat((torch.arange(len(x))[:, None], roi), 1)
aligned = roi_align(self.project(c3), boxes, output_size=(24, 16),
                    spatial_scale=1/16, aligned=True)
```

- `spatial_scale=1/16`：输入 384 → layer3 24，缩放比正好 1/16
- `output_size=(24, 16)`：统一成 24 行 × 16 列
- `aligned=True`：用精确坐标采样，不做取整

输出：**64×24×16**（64 通道，24 行，16 列）

### 5.4 行向量池化 —— 压掉宽度

```python
rows = torch.cat((aligned.mean(-1), aligned.amax(-1)), 1)
```

对每一行（24 行），把宽度方向的 16 个值：

- 取**平均**（64 维）→ 反映整体强度
- 取**最大**（64 维）→ 保留强响应

拼起来 = **128 维/行**，共 24 行 → **128×24**

**为什么压掉宽度**：上下边界只跟"行"有关，宽度方向是干扰。

**为什么 mean 和 max 都要**：mean 平滑，max 保峰值特征，两者互补。

### 5.5 一维行卷积 —— 让相邻行互相参考

```python
self.row_conv = nn.Sequential(
    nn.Conv1d(128, 64, 3, padding=1), nn.ReLU(),
    nn.Conv1d(64, 32, 3, padding=1), nn.ReLU(),
)
rowvec = self.row_conv(rows).flatten(1)     # 32×24 → 768
```

**核心想法**：

> 判断第 10 行是不是边界，光看第 10 行不够，要看**第 8~12 行长什么样**。
> 用 **k=3 的一维卷积，沿着高度方向滑**——每一行都能看到上下各一行。
>
> 这跟二维卷积不同：我们只在"行序列"上做，宽度已经压成一个向量了。

- `padding=1`：保持长度不变（24 行还是 24 行）
- 通道 128 → 64 → 32
- 输出 32×24，拍平成 **768 维**

### 5.6 预测头

```python
self.head = nn.Sequential(
    nn.Linear(768, 128), nn.ReLU(), nn.Dropout(.2), nn.Linear(128, 3)
)
```

768 → 128 → **3**

**为什么是 3 个输出而不是 2 个**：见下一节。

`Dropout(0.2)`：训练时随机丢弃 20% 神经元，防过拟合。

### 5.7 ★ 有序输出（累积 softmax）—— 最核心的设计

**问题**：如果直接回归两个数 `(r_top, r_bot)`，训练早期很容易输出
`r_top > r_bot` 这种非法值，还得额外加损失项去纠正。

**做法**：输出 3 个数，做 softmax 变成三段概率，然后**累加**：

```python
def ordered(z):
    p = (1 - 3e-4) * z.float().softmax(-1) + 1e-4
    return torch.stack((p[..., 0], p[..., 0] + p[..., 1]), -1)
```

```
p = softmax(z)                     p0 + p1 + p2 = 1
r_top = p0
r_bot = p0 + p1
```

**几何解释**：把窗口高度看成 0~1 的一条线，三段正好把它分成：

```
0 ────── r_top ──────── r_bot ────── 1
   p0（上空白）   p1（保留区）   p2（下空白）
```

**为什么这样保证顺序**：

```
r_bot − r_top = (p0 + p1) − p0 = p1 ≥ 0
```

因为 p1 是概率，**恒 ≥ 0**，所以 **r_bot ≥ r_top 永远成立**。

> **上下顺序是数学性质保证的，不是靠损失函数惩罚出来的——结构上就不可能输出一个颠倒的框。**

`1e-4` 的上下限处理是为了：softmax 下溢成 0 时，梯度不会消失。

### 5.8 MC Dropout —— 推理时多次采样

```python
def mc_crop(model, x, roi, samples=16):
    model.eval()
    det = model(x, roi)
    bounds = []
    for m in model.head.modules():
        if isinstance(m, nn.Dropout):
            m.train()                    # ← 故意让 Dropout 保持开启
    for _ in range(samples):
        bounds.append(model(x, roi)['bounds'])
    p = torch.stack(bounds)
    model.eval()
    return {'bounds': p.mean(0), 'std': p.std(0, unbiased=False), ...}
```

**思路**：Dropout 推理时本来是关掉的，我们**故意开着**跑 T 次，取平均。

**好处**：

1. **结果更稳**：单次预测会抖，平均后抖动小很多
2. **顺带得到不确定度**：T 次的标准差越大，说明模型自己也没底

**我们的设置**：生产用 `samples=4`（速度），最大用 16。

> 注意：`samples` 必须 ≥ 2，代码里有断言——1 次采样没有方差，拿不到不确定度。

### 5.9 比例 → 像素

```python
def raw_crop(box, bounds):
    x0, y0, x1, y1 = box
    t, b = bounds
    if not (0 <= t < b <= 1):
        raise ValueError('Invalid predicted interval')
    # Outward rounding avoids discarding a boundary pixel.
    return [int(x0),
            max(int(y0), math.floor(y0 + t*(y1-y0))),
            int(x1),
            min(int(y1), math.ceil (y0 + b*(y1-y0)))]
```

**关键：向外取整**

- 上边界用 `floor`（往下取整 → 保留更多）
- 下边界用 `ceil`（往上取整 → 保留更多）

**为什么**：向内取整会少留一行，长期是系统性偏差。向外取整**宁可多留一个像素也不丢**。

## 6. 训练

### 6.1 损失函数（完整公式）

代码：`ddh_v2.py` 的 `loss_crop`

```
L = L_reg + 0.25·L_IoU + w_in·L_tight + w_out·L_loose + 0.25·L_safe + 0.25·L_qual
```

各项定义：

```
L_reg  = SmoothL1(r̂, r; β = 0.02)
L_IoU  = 1 − IoU(r̂, r)
L_tight = [ r̂_top − (r_top + δ) ]₊ + [ (r_bot − δ) − r̂_bot ]₊
L_loose = [ (r_top − δ) − r̂_top ]₊ + [ r̂_bot − (r_bot + δ) ]₊
L_safe  = SmoothL1(safe_head 输出, r)
L_qual  = BCEWithLogits(quality_logits, quality_label)

δ = 0.04（容差，占窗口高度比例）
w_in = 2.0（往里切，重罚）
w_out = 0.25（往外放，轻罚）
[·]₊ = max(0, ·)（ReLU）
```

对应代码：

```python
total = F.smooth_l1_loss(out['bounds'][m], batch['bounds'][m], beta=.02) \
      + .25 * (1 - iou1(out['bounds'][m], batch['bounds'][m])).mean()

pred, lab = out['bounds'][m], batch['bounds'][m]
# 上边界：pred 更大 = 裁得更紧；下边界：pred 更小 = 裁得更紧
tight = F.relu(pred[:,0] - (lab[:,0] + delta)) + F.relu((lab[:,1] - delta) - pred[:,1])
loose = F.relu((lab[:,0] - delta) - pred[:,0]) + F.relu(pred[:,1] - (lab[:,1] + delta))
total = total + w_in*tight.mean() + w_out*loose.mean()
```

### 6.2 为什么损失函数「偏心」

这是从临床角度做的设计：

| 方向 | 后果 | 权重 |
|---|---|---:|
| **往里切**（预测比标注更紧）| 可能丢掉该保留的解剖结构，影响角度测量 | **2.0** |
| **往外放**（预测比标注更宽）| 只是多留一圈周围组织，顶多不美观 | **0.25** |

> **少留一块该保留的结构会影响测角，是"危险"的；多留一点周围组织只是"不经济"。**
> 两者不能同等对待。

**容差 δ 的意义**：标注本身就有分歧（两个人标同一张图，上边界中位差 10 px）。
容差必须 ≥ 人工噪声，否则模型是在"学习人类的随机性"。

### 6.3 SmoothL1 为什么比 MSE 好

```
SmoothL1(x) = 0.5·x²          if |x| < β
              |x| − 0.5·β     otherwise
```

- 小误差时是平方（梯度小，稳定）
- 大误差时是线性（不会像 MSE 那样梯度爆炸）

对边缘检测这种"大部分准、偶尔飞"的任务特别合适。

### 6.4 IoU 项

```
IoU = 重叠长度 / 并集长度
    = (min(b1, b2) − max(t1, t2)) / ((b1 − t1) + (b2 − t2) − 重叠)
```

关心的是"整体重合得怎么样"，跟单条边的误差互补。

### 6.5 数据增强

只在训练时做，都是**不影响边界定义**的变换：

| 增强 | 参数 | 为什么安全 |
|---|---|---|
| 亮度 | ×0.9~1.1 | 不改变结构位置 |
| 对比度 | ×0.9~1.1 | 同上 |
| 水平翻转 | 50% 概率 | **只翻左右，上下边界定义不变** |
| 高斯噪声 | σ=0.01×像素值 | 模拟不同设备噪声 |

**不做**：上下翻转、旋转、拉伸——这些会改变上下边界的解剖含义，标签就错了。

### 6.6 优化器与学习率

```python
opt = torch.optim.AdamW([
    {'params': model.backbone.parameters(), 'lr': 3e-5},   # 主干：小
    {'params': head,                        'lr': 3e-4},   # 头部：大 10 倍
], weight_decay=1e-4)

sched = torch.optim.lr_scheduler.CosineAnnealingLR(opt, epochs)
nn.utils.clip_grad_norm_(model.parameters(), 5)   # 梯度裁剪
```

**差分学习率的理由**：

- 主干是 ImageNet 预训练的，特征已经很好，**只需微调**
- 头部是随机初始化的，**需要学得快**

**余弦退火**：学习率按余弦曲线从初始值降到接近 0，后期更稳。

**梯度裁剪 5**：防止个别样本产生过大梯度把模型带崩。

### 6.8 数据划分：相似组而不是随机划分

**问题**：如果随机划分，同一患者的连续帧可能一张进训练、一张进测试，
模型见过几乎一样的图，测试成绩虚高。

**做法**：先把高度相似的图归成一组（近重复检测），整组只进一个集合。

> **已知局限**：相似组 ≠ 患者身份。同一患者不同体位、不同时间的图，无法可靠归到一起。

### 6.9 从数据修正获得的提升

项目里最重要的经验：**最大的提升不是换模型，而是修数据。**

| 定位根因：标注口径漂移 | +46 px |
| 三人重标 862 张、统一口径 | — |
| 只重训步骤 B | **17.5 px** |

**提升约 5 倍，模型结构完全没变。**

## 9. 术语表

| 术语 | 含义 |
|---|---|
| **成像窗口** | 截图里真正显示超声内容的矩形区域 |
| **裁剪线** | 最终保留区域的上下两条水平线 |
| **letterbox** | 等比缩放后居中补黑的预处理，避免拉伸变形 |
| **ROIAlign** | 把任意大小区域双线性采样成固定尺寸特征网格 |
| **有序输出** | 用累积 softmax 保证上边界一定在下边界上方 |
| **MC Dropout** | 推理时保留 Dropout，多次采样取平均，降低抖动 |
| **IoU** | 两段区间（或两个框）的重叠比例 |
| **SmoothL1** | 小误差平方、大误差线性的损失函数 |
| **非对称损失** | 两个方向的误差用不同权重，反映现实严重程度差异 |
| **相似组划分** | 高度相似的图整组只进一个数据集，防泄漏 |
| **Graf 法** | 婴儿髋关节超声的标准分型方法 |
| **α / β 角** | Graf 法测量的两个角度，DDH 诊断核心指标 |
| **大转子** | 上边界区域的重要解剖标志，判断标准切面的依据 |

## 10. 附录：核心代码

### 10.1 CropNet 完整定义

```python
class CropNet(nn.Module):
    def __init__(self, pretrained=True, baseline=False):
        super().__init__()
        self.baseline = baseline
        self.backbone = resnet18(weights=ResNet18_Weights.DEFAULT if pretrained else None)
        self.backbone.fc = nn.Identity()
        self.project = nn.Conv2d(256, 64, 1)
        self.row_conv = nn.Sequential(
            nn.Conv1d(128, 64, 3, padding=1), nn.ReLU(),
            nn.Conv1d(64, 32, 3, padding=1), nn.ReLU(),
        )
        self.head = nn.Sequential(
            nn.Linear(512 if baseline else 32*24, 128),
            nn.ReLU(), nn.Dropout(.2), nn.Linear(128, 3),
        )
        self.safe_head = nn.Sequential(nn.Linear(32*24, 64), nn.ReLU(), nn.Linear(64, 3))
        self.quality_head = nn.Linear(512, 1)

    def train(self, mode=True):
        super().train(mode)
        # 冻结 ImageNet BN 统计量（batch 小且相关性强）
        for m in self.backbone.modules():
            if isinstance(m, nn.BatchNorm2d):
                m.eval()

    def forward(self, x, roi):
        b = self.backbone
        x = b.maxpool(b.relu(b.bn1(b.conv1(x))))
        x = b.layer1(x)
        x = b.layer2(x)
        c3 = b.layer3(x)                       # 256 × 24 × 24
        c4 = b.layer4(c3)
        embed = b.avgpool(c4).flatten(1)       # 512
        boxes = torch.cat((torch.arange(len(x), device=x.device)[:, None], roi), 1)
        aligned = roi_align(self.project(c3), boxes, output_size=(24, 16),
                            spatial_scale=1/16, aligned=True)     # 64×24×16
        rows = torch.cat((aligned.mean(-1), aligned.amax(-1)), 1)  # 128×24
        rowvec = self.row_conv(rows).flatten(1)                    # 768
        return {
            'bounds':  ordered(self.head(embed if self.baseline else rowvec)),
            'safe':    ordered(self.safe_head(rowvec)),
            'quality': self.quality_head(embed).squeeze(1),
            'embedding': F.normalize(embed, dim=1),
        }
```

### 10.2 有序输出

```python
def ordered(z):
    """z: (B, 3) 的 logits → (B, 2) 的有序边界比例"""
    p = (1 - 3e-4) * z.float().softmax(-1) + 1e-4
    return torch.stack((p[..., 0], p[..., 0] + p[..., 1]), -1)
```

### 10.3 损失函数

```python
def loss_crop(out, batch, delta=0.04, w_in=2.0, w_out=0.25):
    total = F.smooth_l1_loss(out['bounds'], batch['bounds'], beta=.02) \
          + .25 * (1 - iou1(out['bounds'], batch['bounds'])).mean()

    pred, lab = out['bounds'], batch['bounds']
    tight = F.relu(pred[:,0] - (lab[:,0] + delta)) + F.relu((lab[:,1] - delta) - pred[:,1])
    loose = F.relu((lab[:,0] - delta) - pred[:,0]) + F.relu(pred[:,1] - (lab[:,1] + delta))
    total = total + w_in * tight.mean() + w_out * loose.mean()
    return total
```

### 10.4 MC Dropout 推理

```python
def mc_crop(model, x, roi, samples=16):
    if samples < 2:
        raise ValueError('At least 2 stochastic draws required')
    model.eval()
    det = model(x, roi)
    bounds = []
    for m in model.head.modules():
        if isinstance(m, nn.Dropout):
            m.train()                       # 保持 Dropout 开启
    for _ in range(samples):
        bounds.append(model(x, roi)['bounds'])
    p = torch.stack(bounds)
    model.eval()
    return {'bounds': p.mean(0), 'std': p.std(0, unbiased=False),
            'quality': det['quality'], 'embedding': det['embedding']}
```

## 11. 一句话总结

> **两阶段：规则算法找窗口，ResNet-18 定边界。**
> 只取 layer3（24×24）保住纵向分辨率；
> 把宽度压成行向量，沿高度做一维卷积，让相邻行互相参考；
> 输出三个非负分段并累加，用数学性质保证上下顺序不会颠倒；
> 训练时对"往里切"重罚、对"往外放"轻罚，因为临床上少留结构比多留组织危险得多。
