# CPU/GPU 自动版 v0.4.0

通用包：`D:\ddhmodel\release\DDH裁剪工具_Windows_x64_CPU_GPU_v0.4.0.zip`，约 2.56 GiB。仍保留较小的 CPU 包：`DDH裁剪工具_Windows_x64_CPU_v0.3.2.zip`，约 481 MiB。

两种包都包含软件、现有模型和必要运行组件，没有项目图片、病例样例或标注记录。完整解压后，选择自己存放图片的目录和结果目录即可。Windows 10/11 64 位需具备 .NET Framework 4.8；软件文件夹需要本人可写。

## 自动选择

通用版包含一份具备 CPU/CUDA 能力的 PyTorch 2.5.1+cu121 环境和同一套裁剪参数。兼容的 NVIDIA CUDA 设备可用时使用 GPU，否则使用 CPU。系统需有兼容的 NVIDIA 驱动，CUDA 运行库已随包携带。AMD 和 Intel GPU 在本版使用 CPU。

自动模式遇到 GPU 模型加载或 GPU 推理的 RuntimeError，会加载 CPU 模型并重试，之后继续使用 CPU；原因保存在日志和设备状态提示中。显式指定 CUDA 的调试、测速命令保留直接报错行为，避免把 CPU 结果误记为 GPU 成绩。

这是运行设备选择和软件打包变化，没有重新训练模型，也没有改变标注批准规则。模型推理参数逐项哈希与生产参数一致。

## 性能与选择

在本机 i7-14650HX / RTX 4060 Laptop 上，24 张真实图片、预热后两轮共 48 次预测：CPU 平均 199.31 ms，GPU 平均 66.93 ms，预测阶段约快 2.98 倍。400 张的预测环节估算约为 80 秒和 27 秒，不包含图片导出、ZIP、目录扫描或人工审核时间。

逐张审核 CPU 已足够，400 张连续批量时 GPU 优势更明显。普通电脑或需要较小下载体积时用 CPU 包；兼容的 NVIDIA 显卡和较大批量任务可用通用包。具体方法和原始数据见 `CPU_GPU速度实测_20261015.md`。

## 验收

- 83 项单元/集成测试通过，包含 GPU 模型加载失败与推理失败后的 CPU 回退。
- 六个 Python 后端模块的行覆盖率为 82.7%，不包含前端和原生 C# 外壳。
- 通用 ZIP 在本机独立解压到中文和空格路径，清除 Python / 虚拟环境路径后，GPU 自动启用及 CUDA 设备被屏蔽后的 CPU 路径均通过实际 EXE 验收。
- 两种路径都完成外部图片读取、人工审核、可选 ZIP、草稿退出保存和正常退出；只使用隔离的合成图片，没有把真实医学图片当作测试人工标签。
- 测试设置了不可用的外网代理，以验证推理不依赖在线下载；这不等同于另一台全新 Windows 机器或物理断网环境的验收。

记录位于 `data/portable_gpu_build/acceptance_cuda.json`、`acceptance_cpu.json`、`release_result.json`。最终依赖 NOTICE 和校验清单刷新保留了已验收的 EXE、DLL、前端代码和模型，ZIP 重新通过 CRC 校验。

压缩包内 `release_manifest.json` 提供逐文件 SHA256，`model_manifest.json` 提供参数等价校验。设置和缓存保存在软件自身的 `ddh_multidevice_v2/data/studio_runtime`，分发时请使用原始干净 ZIP。
