# CPU 与 GPU 推理速度实测

在同一台电脑上，对“余”组中均匀抽取的 24 张真实图片，使用相同模型参数、窗口规则和生产预测流程测试。每种配置独立进程运行，先预热，再连续测两轮，共 48 次预测；不同配置按顺序执行，避免争抢硬件影响比较。GPU 计时显式同步 CUDA。

硬件：Intel Core i7-14650HX（16 核 / 24 逻辑处理器）、RTX 4060 Laptop GPU。模型输入保持 384，MC Dropout 仍为 4 次采样，连同确定性输出共执行 5 次网络前向。未导出实际图片，也未生成或改写训练标签。

| 配置 | 连续预测平均每张 | 中位数 | P95 | 85 张预测估算 | 400 张预测估算 |
|---|---:|---:|---:|---:|---:|
| 便携 CPU 依赖（torch 2.5.1+cpu，16 线程） | 199.31 ms | 200.97 ms | 213.36 ms | 16.94 s | 79.72 s |
| GPU（torch 2.5.1+cu121，RTX 4060） | 66.93 ms | 67.59 ms | 74.51 ms | 5.69 s | 26.77 s |
| 同一 CUDA 环境强制 CPU，16 线程 | 201.90 ms | 201.48 ms | 216.13 ms | 17.16 s | 80.76 s |
| 同一 CUDA 环境强制 CPU，4 线程 | 240.58 ms | 240.55 ms | 255.10 ms | 20.45 s | 96.23 s |

GPU 的预测环节约快 2.98 倍。逐张人工审核时，每张只相差约 0.13 秒，CPU 已足够；连续批量处理 400 张时，预测环节约能节省 53 秒。这里的批量数字是单图均值线性估算，不包含目录扫描、PNG 写入、ZIP 压缩、界面启动或人工审核时间，不能作为软件全流程总耗时。

仅模型预测部分（已知窗口，包含读图和预处理）CPU 平均 152.87 ms，GPU 24.57 ms。窗口规则检测仍在 CPU 执行，均值约 45–47 ms，因此整个流程的加速小于神经网络部分的加速。

首次请求含 Python 模块导入和模型加载，CPU 本次为 4.53 秒、GPU 为 4.08 秒。这是单次记录，系统文件缓存未清空，不用于精确比较冷启动。其他电脑的 CPU、显卡、驱动和功耗状态会改变结果。

## 分发决定

保留 v0.3.2 CPU 便携包，适合普通电脑及逐张审核。同时提供 v0.4.0 CPU/GPU 自动版：兼容的 NVIDIA CUDA GPU 可用时使用 GPU，未检测到可用 CUDA 设备时使用 CPU；GPU 模型初始化或首次/后续推理出现 RuntimeError 时切换 CPU 重试。显式指定 CUDA 的调试和测量命令仍会报告错误，不自动改设备，以免误标测量结果。

通用版使用同一套模型参数和一份具备 CPU/CUDA 能力的 PyTorch 运行环境，未重复放入两套模型。CUDA 组件使软件包明显增大，因此较小的 CPU 包仍然有用。AMD 和 Intel GPU 不走 CUDA，本版使用 CPU。

GPU 回退后会在设备状态中显示 CPU，并在状态提示与日志中保留原因。这个更改不重新训练模型、不自动批准标注，也不修改原始图片。

原始实测数据位于 `data/reports/inference_speed_20261015/`：`cpu_portable.json`、`gpu_default.json`、`cpu_default.json`、`cpu_threads4.json`。测量脚本为 `tools/benchmark_inference.py`。
