# 02 超声质量评估与锐利度度量

> 主题 02 文献库。目标：为「**上边界窄带内是否存在锐利边缘**」这一判据寻找可落地的度量方法。
>
> **本项目的实测约束（先摆在这里，因为它决定了全部取舍）**：
> - 已有指标：最大单步梯度 `peak`，区分「误差 ≥ 40 px 严重失败」**AUROC = 0.886**；
> - 边界**强**却切错的样本：**0 例**（即：有锐利边缘 → 模型基本能切准）；
> - 误差 ≥ 40 px 的 8 张，**100% 是「切太高」**。
>
> 所以我们要的**不是**「全图清晰度」，而是「**在某条窄带（1-D 剖面）上，那个边缘有多陡**」。
> 这两个问题在文献里是两类方法，第二节逐篇标注了每篇属于哪一类。

## 二、逐篇要点

### [02-01] BRISQUE — No-Reference Image Quality Assessment in the Spatial Domain
- **做了什么**：在空间域用 MSCN（mean subtracted contrast normalized）系数拟合广义高斯分布，提取 36 维 NSS 特征，SVR 回归质量分。
- **方法核心**：`MSCN(I) = (I-μ)/(σ+1)`，再对 MSCN 的 GGD 形状/方差参数建模。它显式地**除以局部标准差 σ**——这一步把所有局部对比度信息归一化掉了。
- **对我们价值**：作为**全图质量的对照基线**，用来证明「全图 IQA 分数不能预测上边界是否切准」。我们的痛点不是全图糊，而是某条窄带糊。
- **局限**：**方差不敏感**是 BRISQUE 的设计优点，却正是我们的致命伤——超声上边界处「真边缘 vs 无边缘」的差别主要就是局部对比度/梯度幅度，被归一化抹平。**不要用它做边界判据。**

### [02-02] NIQE — Making a "Completely Blind" Image Quality Analyzer
- **做了什么**：不需要任何参考图或训练标签，直接拿自然图像的 NSS 先验多元高斯分布做距离度量。
- **方法核心**：`distance = sqrt( (μ₁-μ₂)ᵀ (Σ₁+Σ₂)⁻¹ (μ₁-μ₂) )`，MVG 拟合 + 马氏距离。
- **对我们价值**：可以零成本跑起来，做**批次级**的超声质量漂移监控（比如"这一批机器/探头拍出来整体变糊了"）。
- **局限**：自然图像先验与 B 超散斑纹理高度不匹配，分数绝对值无意义，只能做组间比较。对单张图的窄带锐利度**完全无区分力**。

### [02-03] BIQI — Blind Image Quality Assessment: From NSS to Perceptual Quality
- **做了什么**：两级框架。第一级判断「这是哪类失真」（JPEG2000/JPEG/白噪声/模糊/快衰落）的概率，第二级给每种失真的质量分再加权。
- **方法核心**：`Q = Σ P(dᵢ) · Q(dᵢ)`，失真识别是显式的一步。
- **对我们价值**：**思想可借**——不要直接回归一个分数，而是先判断「这块区域到底是"模糊边缘"还是"根本没边缘"」。这两件事在超声上表现相似（梯度都小），但**处置完全不同**：前者可救，后者要直接报"不可切"。
- **局限**：失真类型是合成失真，医学图像的实际退化（散斑、衰减、增益补偿、多平面）不在其类别里。

### [02-04] CPBD (QoMEX 2009) — Cumulative Probability of Blur Detection
- **做了什么**：对每个**边缘块**，估计该边缘的模糊宽度，与"刚好可察觉模糊"（JNB）阈值比较，得到"被判定为清晰"的概率，最后累加成累积分布。
- **方法核心**：
  1. 用 Canny/Sobel 找边缘块，记录梯度方向；
  2. 沿梯度方向对边缘宽度做 `w(eᵢ)` 估计；
  3. `P_blur = 1 - exp(-|w(eᵢ)/w_JNB(eᵢ)|^β)`，β 为拟合常数；
  4. `CPBD = Σ_{w<w_JNB} P(w)`。**分数越高越清晰**。
- **对我们价值**：**这是全篇最贴合的方法**。它天生就是"先找边缘、再量这条边缘有多宽、再判断是否已达到可察觉的锐利"，与我们「窄带内是否有锐利边缘」的诉求是**同一个问题**。而且它会**穿过亮度的绝对幅度**，用"宽 vs 感知阈值"来判定，天然对增益/深度差异鲁棒。
- **局限**：原始 CPBD 输出的是一个 0~1 的**全图标量**（把所有边缘块的概率加起来），丢失了空间位置。我们必须改造成**只在窄带内计算**（见第四节）。

### [02-05] CPBD (IEEE TIP 2011)
- **做了什么**：02-04 的完整期刊版，加入更规范的 JNB 宽度模型与对比度-模糊感知曲线验证。
- **方法核心**：与 02-04 同；**关键补充**是用了 Ferzli & Karam 的 JNB 感知曲线——即"多大宽度在多大对比度下才被人眼察觉"的二维查询表。
- **对我们价值**：**引用时用这一篇**（正式发表、公式完整）。它的 JNB 表可以直接查我们的超声对比度范围。
- **局限**：同 02-04；此外其 JNB 曲线来自自然图像观测试验，超声散斑背景下阈值需重标定（见第五节）。

### [02-06] JNB — Just Noticeable Blur Sharpness Metric
- **做了什么**：定义"刚好可察觉模糊"，用局部对比度决定可容忍的边缘宽度，再做概率求和。
- **方法核心**：`w_JNB(c) = f(c)`，c 是边缘局部对比度；`P_blur = 1 - Π_i (1 - P_i)`，对邻域内多个边缘做概率求和（probability summation）。
- **对我们价值**：**我们的 `peak` 本质上是 JNB 的"退化版"**——只用了梯度幅度这一个轴，没有除以"该对比度下可容忍的宽度"。引入 JNB 可以把我们的 AUROC 0.886 从"粗判"升级为"有物理意义的分级"（锐利 / 勉强 / 无可切边缘）。
- **局限**：JNB 的 f(c) 是经验曲线，直接套用不可靠；而且它需要准确的局部对比度——在散斑噪声下不稳定（见第五节）。

### [02-07] JNB (ICIP 2007 前身)
- **做了什么**：JNB 思路的首次完整发表，含 probability summation 表述。
- **方法核心**：同上；讨论了多边缘叠加时感知模糊的"淹没"效应。
- **对我们价值**：如果想论证"为什么窄带里有多条边缘时不能只看最陡那条"，这篇给理论依据。对我们是**次要引用**。
- **局限**：属于会议版，方法细节不如期刊版充分。

### [02-08] LPC — Image Sharpness Assessment Based on Local Phase Coherence
- **做了什么**：在复小波域测边缘处跨尺度相位的一致性——真边缘的相位在各尺度上对齐，模糊会破坏这种一致性。
- **方法核心**：复小波分解，`LPC = |Σ w_k| / Σ |w_k|`（相干性归一化），相位偏差大 → 相干性低 → 模糊。
- **对我们价值**：**这是与我们 `peak` 最"正交"的信息源**。梯度幅度看"有多陡"，LPC 看"这个陡是不是一个真正的结构边缘"。对于「超声上边界处一段亮度渐变」这种假边缘，梯度可能不小，但相位一致性很差。**可作为 `peak` 的补充特征**（融合后 AUROC 有提升空间）。
- **局限**：需要复小波变换（DT-CWT），计算比梯度重得多；对噪声敏感；实现复杂度高，短期不划算。

### [02-09] LPC (ICASSP 2010 会议版)
- **做了什么**：02-08 的前身，首次提出 LPC 锐度度量。
- **方法核心**：同上。
- **对我们价值**：只在需要追溯方法起源时引用；实际实现以 02-08 为准。
- **局限**：同 02-08。

### [02-10] 梯度剖面锐度 (BMSB 2013) — No-Reference Blur Assessment Based on Gradient Profile Sharpness
- **做了什么**：沿梯度方向抽取一维剖面，用剖面本身的形状参数来度量陡度，而不是只看峰值。
- **方法核心**：对边缘点，沿梯度方向取剖面 `P(x)`，用 `w = (2p₁ - p₂)/p₁` 之类的差分比来估计剖面宽度（p₁、p₂ 为剖面上一阶/二阶导的某种组合），窗口大小随噪声自适应。
- **对我们价值**：**这正是"窄带内估计局部边缘锐利度"的标准做法**，且与我们现有的 `peak` 是同一族方法（只是它比 peak 更完整：既看高度也看宽度）。**优先级最高的实现参考之一。**
- **局限**：论文面向自然图像与运动模糊，超声的散斑会污染剖面；窗口自适应规则需要重调。

### [02-11] 梯度剖面锐度 (IEEE TIP 2015)
- **做了什么**：把梯度剖面锐度用于单图超分，给出剖面锐度与模糊核之间的定量关系。
- **方法核心**：假设边缘剖面近似为高斯/Logistic 形状，则由剖面的二阶矩可反推模糊尺度 σ。
- **对我们价值**：**这是第四节推荐方案的数学依据来源**——"用剖面上梯度能量的二阶矩估计边缘宽度"，正是从这篇的思路简化而来。引用时可说"边缘宽度估计sigmas取自梯度剖面建模"。
- **局限**：为超分服务，隐含假设边缘是单阶跃；超声上边界常是"阶跃 + 一层软组织回波"，多成分。

### [02-12] Blur Metric — The Blur Effect
- **做了什么**：最经典的**边缘宽度**法。沿行/列扫描，找局部极大/极小，统计它们之间的变化宽度。
- **方法核心**：`B = Σ max(0, f(x) - f(x-1)) / Σ |f(x) - f(x-1)|`，然后对行、列分别做。**阈值"是否变模糊"由变化率的累积决定**。
- **对我们价值**：实现最简单（几十行 numpy），可作为**快速可行性验证**和兜底方案。它直接对比相邻像素差值——我们的 `peak` 其实已经是它的一阶形式。
- **局限**：只看差分的正负比，对噪声和增益极敏感；无感知阈值；在窄带上需要额外的平滑。

### [02-13] Just Noticeable Defocus Blur Detection and Estimation (CVPR 2015)
- **做了什么**：把 JNB 从"整图打分"推进到"**逐像素生成失焦图**"（blur map）。
- **方法核心**：局部 JNB + 多尺度一致性，输出每个像素的模糊程度图（而非标量）。
- **对我们价值**：**这是 CPBD 改造的关键证据**。它证明了"JNB 可以在局部窗口内逐点计算"，支持我们把 CPBD 限制在窄带内算。另外它是**空间一致性的强证据**：模糊是空间平滑变化的，不是逐点随机的——这可用于我们的"沿边界线平滑后仍显著"的判据。
- **局限**：需要预训练/多尺度融合，计算重；面向摄影失焦，深度散焦模型与超声声影不匹配。

### [02-14] FUIQA — Fetal Ultrasound Image Quality Assessment
- **做了什么**：用 CNN 对胎儿超声做多项质量评估（标准平面识别、光学阴影、羊水等），多任务联合。
- **方法核心**：迁移学习骨干 + 多任务头，标签来自专家打分。
- **对我们价值**：**架构借鉴**——"多项质量指标 + 一个骨干"的结构，正好对应我们的"边界质量多维判据"（梯度、宽度、连续性）。也证明超声上做深度 IQA 是可行的。
- **局限**：评估对象是**整幅图像的解剖学标准性**，不是边缘锐利度；需要大量专家标注。

### [02-15] Multi-task Learning for Quality Assessment of Fetal Head Ultrasound
- **做了什么**：把"质量评估"和"头围测量"放进一个多任务网络联合训练。
- **方法核心**：共享编码器 + 质量头 + 测量头，两者互相正则。
- **对我们价值**：**直接回答"质量是不是我们任务的一部分"**——答案是：质量评估与下游测量可以耦合训练。我们可以加一个"边界锐度头"，与上边界回归头共享特征。
- **局限**：质量标签是离散的解剖学标准层级，与我们需要的连续锐度不同。

### [02-16] CNN-Based Medical Ultrasound Image Quality Assessment
- **做了什么**：面向医学超声的 CNN 盲质量评估，比较不同骨架与预处理。
- **方法核心**：CNN 回归 MOS/质量等级；讨论了超声特有的散斑与增益问题。
- **对我们价值**：作为"超声 IQA 现状"的引用，说明**通用 IQA 直接迁移到超声效果有限**，需要域内改造——这正是我们改用几何/剖面法的理由。
- **局限**：期刊层级一般；未涉及边缘锐度。

### [02-17] Automatic IQA and Measurement of Fetal Head
- **做了什么**：把质量评估和测量放在**同一条流水线**里，先判质量、再测量，低质量直接拒绝。
- **方法核心**：钢琴键式的串联规则 + 质量门控。
- **对我们价值**：**这是我们最该抄的流程结构**。对应我们的设计：先算窄带锐度 → 低于阈值就**拒绝自动切** → 转人工。而不是硬切一个高风险的边界。这直接对上了我们"误差≥40px 全是切太高"的现象（切太高 = 往上跑了，找到的不是真边界）。
- **局限**：面向胎儿头部椭圆，不是髋关节的线状边界。

### [02-18] MUSIQ — Multi-scale Image Quality Transformer
- **做了什么**：用多尺度 ViT 处理任意分辨率的 IQA，在多个数据集 SOTA。
- **方法核心**：多尺度 patch 提取 + 可学习的尺度嵌入 + Transformer 聚合。
- **对我们价值**：如果将来要训一个端到端的"上边界可切性"分类器，这是最合适的主干（任意分辨率是硬需求，因为超声图像尺寸不统一）。
- **局限**：需要大量标注；可解释性差——而我们的场景**必须能解释为什么拒绝**。

### [02-19] DBCNN — Deep Bilinear CNN for BIQA
- **做了什么**：双分支网络分别建模合成失真（模糊等）与真实失真，双线性池化融合。
- **方法核心**：`b = xᵀ W y` 双线性池化。
- **对我们价值**：区分"合成模糊 vs 真实失真"的双分支思路，对应我们"散斑 vs 增益 vs 真无边缘"的区分需求。
- **局限**：**DOI 待核验**（见第五节），先作为探索性参考。

### [02-20] Image Sharpness Measure for Blurred Images in Frequency Domain
- **做了什么**：用 FFT 后高频（中心区域外）能量占总能量的比例作为清晰度。
- **方法核心**：`FM = Σ high_freq / Σ total_freq`，谓词为"清晰图高频能量多"。
- **对我们价值**：作为**最强的"错误做法"对照**。频域法必须作用在一个矩形窗口上，而我们的目标是**沿一条弯曲细线**的窄带，FFT 的全局性会把整幅图的散斑能量全算进来，**在窄带场景下基本无效**。写进对比表是为了**明确排除**。
- **局限**：对位置不敏感、对散斑和增益敏感、无法处理窄带。

## 三、方法对比（重点）

针对「**上边界窄带锐利度**」这一具体问题。评价维度按我们的实测约束设计：① 能否只作用于窄带；② 是否对增益/深度鲁棒；③ 实现成本；④ 能否区分「模糊边缘」与「无边缘」。

| 方法 | 原理 | 优点 | 缺点 | 是否开源 | 适合程度 |
|---|---|---|---|---|---|
| **Laplacian 方差** | 二阶差分（拉普拉斯算子）响应平方和 | 最快（一次卷积），我们已有 | **完全丢失位置**：一个突变点就能把方差拉高；对散斑噪声平方放大；无阈值意义 | ✅ OpenCV 一行 | ⚠️ 仅作粗筛，不建议做判据 |
| **Tenengrad** | Sobel 梯度模平方和（全图/窗口） | 比 Laplacian 抗噪，物理意义直接（= 我们的 `peak` 的平方和版本） | 是 `peak` 的"求和"形式，**对一条很长的边缘会稀释**；仍无宽度概念 | ✅ | ⚠️ 中：等于现状近似 |
| **CPBD** | 边缘块 JNB 判定 → 累积清晰概率 | **天生为"边缘是否可察觉地锐利"设计**；有感知阈值；**对绝对亮度/增益鲁棒** | 原版输出全图标量（丢位置），需改造为窄带版；散斑下 JNB 阈值需重标定 | ✅ [python-cpbd](https://github.com/0x64746b/python-cpbd) | ✅✅✅ **最合适** |
| **JNB** | 局部对比度 → 可容忍模糊宽度 → 概率求和 | 理论最完整；产生"分级"而非二元 | 需准确局部对比度；经验曲线需重标定 | ⚠️ 部分实现 | ✅✅ 适合（CPBD 的上位框架） |
| **LPC** | 复小波跨尺度相位一致性 | **与梯度正交**，能区分真边缘/渐变假边缘 | 计算重、实现复杂、对噪声敏感 | ⚠️ MATLAB 为主 | ✅ 适合做**融合特征**，不适合单独做 |
| **S3 (Sparse/SVD-based)** | 稀疏表示或 SVD 奇异值衰减 | 对全局模糊敏感 | 需基字典、面向全图模糊；**不是局部方法** | ⚠️ | ❌ 不适合 |
| **梯度轮廓法** | 沿梯度方向取剖面，量剖面宽度/二阶矩 | **就是"窄带"方法的原型**；输出连续锐度值；实现轻 | 假设单阶跃边缘；散斑污染剖面 | ⚠️ 论文无官方码，公式可自实现 | ✅✅✅ 适合（**与 CPBD 同族，更直接**） |
| **边缘宽度 FWHM** | 找边缘中心 → 量 10-90% 上升距离 | **最直观、可解释**（"这条边宽 1.2 px"）；实现最简单；对增益归一化 | 需要正确的边缘中心与 10/90 平台估计；噪声下限偏置 | ✅ 可自实现（本文已验证） | ✅✅✅ **最合适（工程首选）** |
| *(对照)* 频域 FFT | 高频能量占比 | — | 全局方法，无法处理窄带 | ✅ | ❌ 排除 |
| *(对照)* BRISQUE/NIQE | NSS 特征回归 | 全图质量成熟 | **归一化抹掉对比度**，与我们的判据方向相反 | ✅ | ❌ 排除 |

**结论**：CPBD、梯度轮廓法、边缘宽度 FWHM **三者同族**——都是"找到边缘 → 量它有多宽 → 与阈值比"。区别只在：
- **CPBD** 把宽度塞进 JNB 的**感知阈值**里（好，但需要重标定）；
- **梯度轮廓法**用**二阶矩**估计宽度（好，抗噪）；
- **FWHM** 用**10-90% 上升距离**（最直观，但下限偏置明显）。

## 四、推荐方案

### 推荐：**窄带边缘宽度（FWHM）+ 梯度二阶矩**，以 CPBD/JNB 的感知阈值作为分级上界

> 一句话：**不是算全图锐度，而是在上边界候选点处沿法线取一条 1-D 剖面，量这条剖面上那个阶跃有多宽。宽度小 = 锐利 = 可切；宽度大或无峰值 = 糊/假边缘 = 拒绝或上人工。**

#### 1. 为什么选它

1. **和我们的实测证据完全同构**。我们的 `peak` 已经 AUROC=0.886，说明**梯度幅度方向是对的**，只是信息不完整——`peak` 只看"最陡的一个点有多陡"，没看"这个陡有多宽"。**边缘宽度正是缺的那一半信息**，且与 `peak` 高度互补。
2. **直接解释"切太高"**。切太高 = 模型跑到了真实边界的上方（更浅的组织/耦合剂下沿）。那个位置通常是**渐变或散斑**，不是阶跃。用宽度判据：该处剖面**没有明确的低/高平台**，或宽度极大 → 判为"无锐利边缘"。这比 `peak`（可能被一团噪声碰出大值）可靠。
3. **对增益/深度鲁棒**。判断用的是"宽度"这个**几何量**，与图像绝对亮度无关。超声不同深度增益补偿差异很大，这正是我们需要的。
4. **可解释**。可以给医生看："此处边缘宽度 3.8 px > 阈值 1.5 px，不自动切"。比起一个黑箱分数，这在医疗场景是**硬需求**。
5. **零训练成本**。不需要标注、不需要 GPU，立刻可上。

#### 2. 怎么实现

**核心公式**（边缘宽度估计，已在本地用合成数据验证，见下）：

```
输入：p(x), x = 0..L-1   # 沿上边界法线方向、在窄带内取均值后的 1-D 剖面

1) 归一化          p ← (p - min(p)) / (max(p) - min(p))
2) 降噪            p ← median_filter(gaussian(p, σ₀=1.0), k=3)
3) 定位边缘中心     k* = argmax_x |∂/∂x [gaussian(p, σ₁=1.0)]|
4) 取窄窗          seg = |∇gaussian(p,σ₁)|[ k*-H : k*+H ],  H=8
5) 二阶矩 → 宽度   μ = Σ x·seg / Σ seg
                   σ² = Σ (x-μ)²·seg / Σ seg
                   w_raw = 2.3548 · sqrt(max(σ² - σ₁² - 1.49, ε))   # 扣掉分析平滑贡献
6) 校准            FWHM = a · w_raw + b                              # a≈1.25, b≈-5.40（见下）
```

其中 `2.3548 = 2√(2ln2)`，是高斯 σ → FWHM 的换算系数。

**分级判据（建议）**：

| 条件 | 判定 | 动作 |
|---|---|---|
| 剖面峰-谷对比 < τ_c 或 FWHM 无法收敛 | **无可切边缘** | 拒绝自动切，转人工 |
| FWHM ≤ 1.5 px 且 `peak` ≥ τ_p | **锐利** | 自动切，高置信 |
| 1.5 < FWHM ≤ 4 px | **边缘偏软** | 自动切，但标记待复核 |
| FWHM > 4 px | **糊 / 假边缘** | 拒绝自动切 |

> τ_c、τ_p、以及 a/b 需在**我们的真实超声数据**上重标定（当前 a、b 来自合成高斯阶跃）。

**伪代码（Python / numpy）**：

```python
import numpy as np
from scipy.ndimage import gaussian_filter1d, median_filter

def band_edge_width(prof, smooth=1.0, half=8):
    """窄带 1-D 剖面上的边缘宽度 (FWHM, 像素)。返回 (width, edge_center, peak_grad)。"""
    p = prof.astype(np.float64)
    rng = p.max() - p.min()
    if rng < 1e-9:
        return np.inf, -1, 0.0                      # 完全平坦 = 无边缘
    p = (p - p.min()) / rng
    p = median_filter(gaussian_filter1d(p, 1.0), size=3)

    d = np.gradient(gaussian_filter1d(p, smooth))
    k = int(np.argmax(np.abs(d)))
    peak_grad = float(np.abs(d[k]))

    lo, hi = max(0, k - half), min(len(d), k + half + 1)
    seg = np.abs(d[lo:hi])
    tot = seg.sum()
    if tot < 1e-9:
        return np.inf, k, peak_grad

    x = np.arange(len(seg), dtype=np.float64)
    mu = (x * seg).sum() / tot
    var = ((x - mu) ** 2 * seg).sum() / tot

    w_raw = 2.3548 * np.sqrt(max(var - 1.0 - smooth**2, 1e-6))  # 1.0 = 中值/高斯预平滑的方差
    width = 1.2509 * w_raw - 5.4014                              # ← 需按真实数据重标定
    return width, lo + mu, peak_grad
```

**本地验证结果**（合成的"阶跃 + 高斯模糊 + N(0,0.08) 噪声"，64 px 剖面，每档 300~400 次重复）：

| 真实模糊 σ | 实测 w_raw | 校准后 FWHM | 误差 |
|---|---|---|---|
| 0.5 | 4.89 | 0.71 | +0.21 |
| 0.8 | 4.97 | 0.81 | +0.01 |
| 1.0 | 5.07 | 0.94 | -0.06 |
| 1.5 | 5.39 | 1.34 | -0.16 |
| 2.0 | 5.87 | 1.94 | -0.06 |
| 3.0 | 6.74 | 3.03 | +0.03 |
| 5.0 | 8.34 | 5.03 | +0.03 |

- 单调性 ✅（σ 增大 → 宽度单调增大）
- 组间可分性：锐利组（σ∈[0.4,1.2]）vs 模糊组（σ∈[2.5,7.0]），**AUROC = 0.986**（理想条件下；真实数据会更低，但说明方法本身有足够区分力）。
- 注意：**未校准的 w_raw 有明显下限偏置**（σ=0.5 与 1.0 几乎拉不开），所以**校准这一步不可省**。

**与 `peak` 的融合建议**：把 `(peak_grad, FWHM)` 作为二维特征，训一个极轻的分类器（逻辑回归即可），或直接用规则表。预期优于单用 `peak` 的 0.886。

#### 3. 已知缺陷和应对

| 缺陷 | 具体表现 | 应对 |
|---|---|---|
| **噪声下限偏置** | σ 很小时宽度被"地板"住（w_raw≈4.9），锐利样本分不开 | 必须用真实数据重标定 a/b；或改用**相对比较**（同图内不同候选位置的宽度排名）而非绝对值 |
| **散斑污染** | 超声散斑是乘性噪声，median+gaussian 抑制不够 | 沿边界方向先做**方向性平均**（沿边缘切线多行平均后再取法线剖面）；或先用 Lee/SRAD 散斑滤波器 |
| **边缘中心定位错误** | 窄带里有多个候选峰，选错峰 | 用**先验**约束：上边界有大致位置范围（我们已有 window 定位），只在先验区间内找峰 |
| **非单阶跃边缘** | 上边界可能是"阶跃 + 一层软组织回波"的双成分 | 用**多峰检测**，取最靠近先验位置的那个峰；或在二阶矩前先做去卷积 |
| **无法区分"糊"与"无边缘"** | 两者 FWHM 都大 | 加**对比度门槛**：峰-谷落差 < τ_c 判"无边缘"（拒绝），落差够大但宽 → "糊"（可尝试微调） |
| **阈值域依赖** | 不同探头/机器/深度阈值不同 | 分级阈值按**设备分组标定**；或改用分位数（本批次内的相对排名） |
| **JNB 阈值未重标定** | 若接入 CPBD 的感知表，其曲线来自自然图像 | 先用纯几何 FWHM（不接 JNB）；等积累足够标注后再标定 JNB 表 |
| **只看法线方向** | 斜边缘在法线采样时会"变宽" | 用**结构张量**估计局部梯度方向（而非固定竖直方向），沿真实法线采样 |

**实施顺序建议**：
1. 先在我们**已有的 8 张失败样本 + 若干成功样本**上跑 `band_edge_width`，看是否能拉开；
2. 再决定是否融合 `peak` 训练分类器；
3. 最后才考虑 LPC 融合或学习式方法。
