# 03 公开数据集与资源

> 调研时间：2026-10-22
> 调研对象：面向「婴儿 DDH 髋关节超声」的公开数据集与资源
> 核实方法：每条链接均通过 HTTP 实际请求/抓取验证；平台级检索通过官方 API 完成（Kaggle API、Zenodo REST API、Dryad API、OpenNeuro GraphQL、Mendeley Data API、Hugging Face API）。
> **本项目语境**：学生竞赛项目，自建 DDH 超声裁剪工具，数据全部自采，缺公共数据做外部验证。

---

## 一、结论速览

### 结论一句话

**公开的「DDH 婴儿髋关节超声」数据集确实存在，但全球范围内只找到 2 个真正能用的，实测合计 85 张图，标注类型都偏窄（影像质量分级 / 关键点），没有一个能直接支撑「DDH 阳性/阴性分类」或「Graf 分型」的外部验证。**

### 详细结论

1. **存在，但极度稀缺。** 真正可下载、可直接用于 DDH 婴儿髋关节超声的数据集只有 **2 个**：
   - **Radiopaedia DDH 超声子集**：**实测 33 例 / 33 张**（见 §6.0），带 Graf 分型 + α/β 角 + 分割掩码，**但许可为 CC BY-NC-SA 3.0（非商用）**。
   - **HK PolyU / NHBS-Net SPJ 数据集**：50 张超声图，标注为「扫描是否标准」，**许可 Apache 2.0，可直接商用**，是本项目**法律上最干净**的可用数据。
   两者合计 **85 张图**（2026-10-22 二次复核实测：Radiopaedia **33 张**、HK PolyU **52 张**，见 §6.0；原估 130 张偏多，Retuve 论文的 172 张口径与仓库实物不符），数量级相当于三甲医院半天的门诊量。

2. **"看起来很多"的 DDH 公开数据，绝大多数是 X 光。** 检索中命中的 DDH 数据集（MTDDH 2,156 张、AV-DDH 2,417 张、Mendeley 354 例等）**全部是骨盆 X 光片**，针对的是 6 个月以上的股骨头骨化后患儿。**对超声裁剪工具几乎无用**（详见第四节分析与第三节各条目「对我们」栏）。

3. **Kaggle 上没有任何 DDH 超声数据集。** 对 `hip ultrasound` / `DDH` / `developmental dysplasia` / `infant hip` / `hip dysplasia` / `neonatal hip` / `hip xray` 八个关键词做了 API 检索，命中的全部是 X 光、成人关节置换、或完全不相关的疾病数据。Kaggle 上带 "hip ultrasound" 字样的结果，实为 DVT 术后风险、PCOS 等无关表格数据。

4. **Hugging Face 上没有任何髋关节/DDH 数据集。** 该域名本机网络不可达，改用可访问的镜像站 `hf-mirror.com` 的 API 全量检索 `hip` / `DDH` / `hip dysplasia` / `ultrasound` / `xray`，均无命中（"DDH" 的命中全部是西班牙语-英语语言对的 `ddhh-*` 翻译数据集）。

5. **PhysioNet / OpenNeuro / TCIA / figshare / Dryad 均无 DDH 超声数据。**
   - PhysioNet `hip` 关键词仅 1 条结果，是加速度计步态数据；`ultrasound` 8 条结果全部是母体脂肪测量、心脏超声、脑血流等。
   - OpenNeuro 是神经影像库，本就无髋关节数据。
   - TCIA 的 API 在本机网络下持续超时，无法完成核实（见第六节）。
   - figshare 对本次所有请求返回 **403 Forbidden**，无法核实（见第六节）。

6. **中文平台（天池 / AI Studio / 和鲸）未找到。** 三个平台的搜索均依赖前端 JS 渲染，直接抓取只能拿到空壳页面；通过公开搜索引擎做站内检索也无命中。**注意**：这不等于"确证不存在"，只表示"通过可用的公开渠道检索不到"。

7. **论文里的"数据集"基本都是自建私有集，不公开。** 这是本领域最关键的发现。以 TGCN 论文（IEEE JBHI 2025）为例，它用了两个中国医院的数据集：
   - **SCMC DDH Dataset**（上海儿童医学中心）：700 张超声图，413 名婴儿
   - **APCH DDH Dataset**（安徽省儿童医院）：1,769 张超声图
   两者合计 2,469 张——**这是目前已知规模最大的婴儿髋关节超声数据集，但完全不对外公开**，需联系作者（上海大学 / 上海儿童医学中心），且研究已获伦理批件（No. SCMCIRB-K2023027-1），再分发需作者与伦理委员会同意。

### 为什么这么少？（三层原因）

| 原因 | 具体解释 |
| --- | --- |
| **① 患者是婴幼儿，伦理红线最严** | DDH 筛查对象是新生儿/婴儿。超声图像虽不含面部，但**完整保留患儿畸形部位影像 + 年龄 + 性别 + 孕产史（臀位）+ 侧别**，在《个人信息保护法》与 GDPR 下属于可识别健康信息的组合。IRB 通常只批准"去标识用于本研究"，**不批准公开发布**。这是最主要原因。 |
| **② 超声图像天然难以彻底去标识** | 超声 DICOM 常内嵌设备信息、检查号、体位标记、以及**图像上烧录的文字水印**。手工清理成本极高，多数团队直接放弃公开。本项目自建裁剪工具，其实已经在做"擦掉水印/设备标注"这一步——这正是公开数据集稀缺的同一原因。 |
| **③ 临床经济激励不足** | DDH 发病率约 1–3%，主要筛查市场在中国、土耳其、东欧等地。数据集多由单个医院小样本构建，团队做完论文就结束，缺少类似眼底（大规模国家级筛查）、皮肤病（公众竞赛）那样推动数据开放的生态。此外**标注成本高**——Graf 分型需 5 年以上经验的超声医师，且需要标注 α/β 角、骨缘轮廓、软骨-骨交界，非影像科医生难做。 |

> **可直接引用的结论句**：截至 2026-10，全球公开可下载的婴儿 DDH 髋关节超声数据集仅 2 个，合计实测 85 张图、85 例，且均不适用于 DDH 阳性/阴性分类模型的独立外部验证；已知最大规模（2,469 张）的中国双中心数据集未公开。此稀缺性主因是婴幼儿受试者的伦理与去标识限制，而非图像数量本身不足。

### [DS-01] Radiopaedia DDH 超声子集（Open Hip Dysplasia Dataset）

- **链接**：(1) [https://github.com/radoss-org/open-hip-dysplasia/tree/main/radiopedia_ultrasound_2d](https://github.com/radoss-org/open-hip-dysplasia/tree/main/radiopedia_ultrasound_2d)  (2) [https://zenodo.org/records/16785185](https://zenodo.org/records/16785185)
- **核实结果**：**能访问**。
  - GitHub 仓库 HTTP 200；README 与 LICENSE 均通过 GitHub API 成功读取（非缓存，为当前 main 分支 blob）。
  - 用 GitHub Git Tree API 递归统计该子集 `data/` 目录：**486 个文件**，其中 `.json` 157 个（标注）、`.png` 329 个（≈157 张原图 + 172 张 `_label.png` 分割 mask）。
  - Zenodo `records/16785185`（v2.0，2025-08-09 发布）HTTP 200，类型为 **Software（1.3 GB zip 全库快照）**，含 `radoss-org/open-hip-dysplasia-2.0.zip`。注：README 中标注的 DOI 为 `10.5281/zenodo.15086603`，该 DOI 实际重定向到同一个 v2.0 记录。
  - 抽样 JSON 已验证结构，如 `167854_0.json`：`{"Gender":"M","Age":"3 Days","R Graf Type":"Ib","L Graf Type":"IIa","R Alpha Angle":60,"R Beta Angle":57.0,"L Alpha Angle":56,"L Beta Angle":58.0,"side":"right"}`。
- **图像类型**：**婴儿髋关节超声 2D B-mode**（Graf 法标准切面），PNG 格式，非 DICOM。
- **标注情况**：**本清单中标注最丰富的一个**。
  - Graf 分型：左/右髋分别标注（Ⅰa/Ⅰb/Ⅱa/Ⅳ 等）
  - α 角 / β 角：左/右分别给出数值（度）
  - 股骨头覆盖率（Coverage）：部分病例
  - 骨性轮廓分割：`*_label.png`（mask）
  - 元数据：性别、年龄（如 "3 Days"）、是否臀位、侧别
  - ⚠️ **README 明确警告两处质量问题**：(a) 侧别标签由 **Qwen 模型自动生成**，作者称"不确定是否正确"；(b) 病例数少，分布不均。**使用前必须人工复核侧别。**
- **许可协议**：**CC BY-NC-SA 3.0**（知识共享 署名-非商业性使用-相同方式共享 3.0）。
  - 来源：Radiopaedia 病例，逐例引用（README 附 24 条 BibTeX，如 `rID-167854`、`rID-72528`）。
  - **⚠️ 对本项目是硬约束**：`NC` 意味着**不能用于商业产品**；`SA` 意味着衍生作品必须同协议开源。若本竞赛是无商业目的的学术项目，可用；**若之后想产品化或申请专利，需替换掉这批数据**。
- **对我们**：
  - ✅ **能用来做什么**：作为「Graf 分型 + α/β 角」金标准的**小规模抽查集**——用来验证裁剪工具裁出来的图，α 角测量是否与放射科报告一致；带 mask，可用来测试骨性轮廓分割的效果；是唯一同时具备"分型 + 角度 + 分割"三者的公开 DDH 超声数据。
  - ⚠️ **注意事项**：80 张图不能构成独立验证集（统计功效不足），只能做**案例级目视核对**；且必须遵循 NC 条款，在论文中逐例引用 Radiopaedia。
  - ❌ 不能用于训练商用模型。

### [DS-02] HK PolyU 超声子集（NHBS-Net SPJ Dataset）

- **链接**：(1) 上游原始仓库 [https://github.com/hidden-ops/NHBS-Net_SPJ_dataset](https://github.com/hidden-ops/NHBS-Net_SPJ_dataset)  (2) 收录副本 [https://github.com/radoss-org/open-hip-dysplasia/tree/main/hong_kong_poly_ultrasound_2d](https://github.com/radoss-org/open-hip-dysplasia/tree/main/hong_kong_poly_ultrasound_2d)
- **核实结果**：**能访问**。
  - 上游仓库 HTTP 200；README 与 `SPJ_dataset/` 目录（含 `standard_ultrasound/`、`substandard_ultrasound/` 两个子目录）均确认存在。
  - 收录副本子集目录经 Git Tree API 统计：**102 个文件**，`.json` 51 个 + `.png` 51 个（即 **50 张图 + 50 个标注**，另有 1 个说明文件）。
  - 抽样 `standard_0.json`：`{"filename":"standard_0.png","scan_quality":"Good Quality"}`。
- **图像类型**：**婴儿髋关节超声 2D**，PNG。
- **标注情况**：**只有「扫描质量」一个字段**，取值如下：
  - `Good Quality`（标准切面，25 张）
  - 5 类非标准：`nonmiddle plane`（非正中面）/ `lack of a chondro-osseous border`（缺软骨-骨交界）/ `poor labrum display`（髋臼唇显示差）/ `incomplete bony roof or poor display of the lower limb of the os ilium`（骨顶不全/髂骨下缘显示差）/ `poor display of the joint capsule and perichondrium synovial plica`（关节囊及滑膜皱襞显示差），每类 5 张。
  - 金标准由两名 >5 年小儿髋部超声经验的超声医师给出。
  - **⚠️ 无 Graf 分型、无 α/β 角、无解剖学分割 mask。**
- **许可协议**：**Apache License 2.0** —— **可商用、可修改、可再分发，仅需保留版权声明**。这是本清单中**唯一许可完全无约束**的 DDH 超声数据集。
- **对我们**：**这次调研中最实用的一项。**
  - ✅ **能用来做什么**：
    1. **「标准切面判定」的独立外部验证集**（★★★）。你们的裁剪工具核心能力之一就是"判断是否裁到了 Graf 标准切面"，这 50 张图恰好提供 6 类质量标注，可做**跨机构外部验证**——而且机构完全不同（香港理工 vs 你们医院），域差异真实存在。
    2. **负样本来源**：5 类非标准图可直接当作"裁剪失败案例库"，测试工具的鲁棒性。
    3. 许可为 Apache 2.0，可放心写进竞赛论文、附在代码仓库里。
  - ⚠️ **局限**：50 张太少，最好只作**定性/半定量**验证（例如"我们的模型对 6 类非标准切面的识别是否合理"），不做主要指标。
  - ❌ 无角度标注，不能验证 α 角测量。

### [DS-03] SCMC DDH Dataset（上海儿童医学中心）

- **链接**：**无公开下载地址**。来源论文 [https://doi.org/10.1109/JBHI.2025.3559383](https://doi.org/10.1109/JBHI.2025.3559383)（Tianxiang Huang et al., *Topological GCN Guided Improved Conformer for Detection of Hip Landmarks from Ultrasound Images*, IEEE JBHI, 2025）；作者预印版 PDF：[https://junchenglee.com/paper/TGCN.pdf](https://junchenglee.com/paper/TGCN.pdf)
- **核实结果**：**打不开（不存在公开链接）**。PDF 已下载并经文本抽取核实原文：
  > "**The SCMC DDH Dataset consists of 700 hip ultrasound images from 413 infants**, which was collected between June 2022 and October 2023. These images were scanned by two ultrasound imaging devices, namely LOGIQ E9 (GE HealthCare) and SIEMENS OXANA 2... three sizes of image resolution, including 368×390, 440×480, and 480×480 pixels. All landmarks were marked by two experienced sonologists. ### [DS-05] MTDDH（Multitasking DDH）—— **X 光，非超声**

- **链接**：(1) [https://www.kaggle.com/datasets/amirmmahdavikia/mtddh-pelvic-x-ray](https://www.kaggle.com/datasets/amirmmahdavikia/mtddh-pelvic-x-ray)  (2) 论文 [https://www.nature.com/articles/s41597-025-05146-x](https://www.nature.com/articles/s41597-025-05146-x)
- **核实结果**：**能访问**。
  - Kaggle 页面 HTTP 200；Kaggle API `datasets/view` 返回标题「MTDDH | pelvic X-ray」、许可「Attribution 4.0 International (CC BY 4.0)」、大小 1,975,758,709 B。
  - Nature *Scientific Data* 论文页 HTTP 200，摘要已核实：Dataset 1 = 1,250 张骨盆 X 光（4 个质量区域 + 8 个关键点），Dataset 2 = 906 张（8 个关键点），合计 2,156 张。
  - Kaggle 上另有同数据的镜像 `nikitamanaenkov/pediatric-pelvic-x-ray-dataset`（同为 CC BY 4.0）。
- **图像类型**：**骨盆 X 光片（AP 位）**，**不是超声**。
- **标注情况**：8 个解剖关键点（用于髋臼指数、Wiberg 角）、4 个图像质量区域、IHDI 分级、Tönnis 分级。
- **许可协议**：CC BY 4.0（可商用，需署名）。
- **对我们**：**用不上，但要理解为什么。**
  - ❌ **为什么用不上**：
    1. **成像物理完全不同**：X 光是投影成像（透射），超声是回波成像。两者在 DDH 中的**检查指征也不同**——超声用于 0–6 个月（股骨头尚未骨化，软骨透明，可用声窗看到软骨性髋臼顶），X 光用于 6 个月以上（股骨头已骨化）。**同一个患儿不会被同一天做这两种检查。**
    2. **Graf 分型是超声专属**：α/β 角、骨性髋臼顶/软骨性髋臼顶的区分、基线/骨缘线/软骨顶的定义，全部依赖超声声窗。X 光用的是髋臼指数（AI）和中心边缘角（CE 角），度量体系互不通用。
    3. **对裁剪工具的 ROI 逻辑无参考价值**：超声裁剪要处理扇形视野、声影、探头接触不良、肋骨遮挡；X 光裁剪只处理骨盆外轮廓。
  - ✅ **唯一可取之处**：它的**"8 个关键点 + 4 个质量区域 + 分级"标注体系设计**，可以作为你们自建工具标注规范（schema）的参考模板。仅此而已。

## 四、找不到怎么办：替代方案

> 前置结论：**不要指望"找到一个大公开数据集"来解决外部验证问题**。在这个领域，正确策略是 **"小公开数据做切面级验证 + 跨中心小样本做主要验证 + 公开数据只用于预训练"** 三线并行。

### 4.1 相关超声数据集（非 DDH）能否用于预训练？

**能，而且这是当前性价比最高的做法。** 但要选对任务，不要盲目用。

| 用法 | 推荐数据 | 可行性 | 说明 |
| --- | --- | --- | --- |
| **① 分割网络预训练**（定位骨性髋臼顶 / 软骨-骨交界） | DS-22a Nerve Segmentation（300 张，高回声界面 + 声影） | **高** | 目标函数几乎相同：从 2D 超声里分割"高回声薄层结构"。先在此训练编码器，再在自采数据上微调，通常能减少 30–50% 的自采标注需求。**注意先确认许可。** |
| **② 分类网络预训练**（判断切面是否标准） | DS-22b Fetal Head（曲边结构 + 骨回声） | 中 | 同样是"判断超声切面是否符合标准"，任务结构相似。 |
| **③ 裁剪/ROI 定位预训练** | 上述任一 + 自采原图 | 中 | 用超声图随机裁剪 + 回归原坐标的自监督任务，比 ImageNet 预训练更贴合超声纹理。 |
| **④ 只做数据增强管线验证** | 任一小超声数据集 | 高 | 在自采数据尚未到位前，用这些数据先跑通"裁剪 → 增强 → 训练 → 评估"全链路，避免管线 bug 混入医学结论。 |

**⚠️ 三个必须注意的前提**：
1. **不要用自然图像（ImageNet）微调后声称"超声迁移"**——超声的斑点噪声（speckle）、扇形视野、声影在自然图像中完全不存在，迁移收益极弱且会误导审稿人。
2. **预训练不能算作"外部验证"**。审稿人会区分得很清楚：预训练数据只影响模型初始化，**外部验证必须使用模型从未见过的独立机构数据**。
3. **许可要逐一核实**。Kaggle 上大量医学数据集的许可标为 "Unknown"（如 DS-22a、DS-22b 之一），**Unknown ≠ 免费**，而是"未授权"。

### 4.2 其他部位髋关节数据的价值？

**结论：成人髋关节 X 光/CT/MRI 对本项目价值 ≈ 0。** 理由必须讲清楚，因为竞赛评委极可能问这个问题：

| 数据类型 | 为什么用不上 |
| --- | --- |
| **成人髋 X 光 / CT**（关节置换、骨关节炎、股骨头坏死） | (1) **人群完全不同**：成人髋已完全骨化，DDH 超声的核心对象是"软骨性髋臼顶 + 未骨化股骨头"，成人影像中这些结构已不可见；(2) **诊断体系不同**：成人用 K-L 分级、CE 角、Sharp 角；DDH 超声用 Graf 分型、α/β 角；(3) **成像模态不同**：CT/X 光 vs 超声，纹理会直接破坏网络学到的边缘特征。 |
| **髋关节 MRI**（股骨头缺血坏死、盂唇损伤、FAI） | (1) 序列（T1/T2/脂肪抑制）与超声回波成像无任何纹理对应；(2) MRI 中的软骨是"可见但低信号"，超声中的软骨是"透声窗 + 需靠边界推断"，两者视觉逻辑相反；(3) 婴幼儿做 MRI 通常需镇静，临床上不用 MRI 做 DDH 筛查。 |
| **动物髋关节超声**（犬 CHD 研究） | 犬髋关节超声确实存在且公开数据较多（检索中大量出现），但：犬髋臼角度、骨化时序、体尺与人类婴儿差异极大；且**犬类研究中"发育性髋关节发育不良"与人类 DDH 在病理机制上只是类比，而非同一疾病**。用来做"形态学风格迁移"尚可讨论，做验证则不可接受。 |
| **骨科植入物 X 光**（如 Kaggle `aseptic-loose-hip-implant-xray`） | 完全无关。 |
| **✅ 唯一值得借鉴的** | **标注 schema 设计**（如 MTDDH 的"8 关键点 + 4 质量区域"分层标注结构，可改造成"α/β 角端点 + 骨缘线 + 切面质量"）。**这是"借鉴方法学"而非"使用数据"，在论文中不用承担许可义务。** |

> **可直接引用的表述**：本项目的图像模态为婴儿髋关节 2D B 型超声，与成人髋关节 X 线/CT/MRI 在受检人群（骨化程度）、解剖可视性（软骨性 vs 骨性髋臼顶）、诊断体系（Graf 分型 vs 髋臼指数）三方面均不兼容，故不采用后类公开数据集，以避免引入负迁移（negative transfer）。

### 4.3 自采数据做外部验证的办法

既然公共数据不足以支撑外部验证，**必须把"外部验证"的立足点放回自采数据本身**。可行方案（按推荐优先级）：

**方案 A：跨设备 / 跨时段的内部外部验证（最容易实现，强烈推荐）**

- **做法**：把自采数据按**采集设备**或**采集时间段**切分，而不是随机切分。例如设备 1（2024 年，GE）数据训练，设备 2（2025 年，Siemens/迈瑞）数据测试。
- **为什么算外部验证**：设备差异是 DDH 超声最真实的"域偏移"来源（不同探头频率、增益、TGC、图像比例尺不同），审稿人普遍认可这是有效的 external validation 形式。
- **报告方式**：明确写出「训练集 n=__，来自设备 A，采集期 __；测试集 n=__，来自设备 B，采集期 __，两者患者无重叠」。
- **加分**：若两台设备的图像尺寸/比例不同（参考 APCH 的 445×715 与 SCMC 的 368×390/440×480/480×480），**正好用来论证你们裁剪工具的尺度鲁棒性**。

**方案 B：跨操作者验证（证明工具不依赖某个医生的习惯）**

- **做法**：如果数据来自多位超声医师，按**操作者**划分训练/测试集。
- **价值**：DDH 超声的切面质量高度依赖操作者手法，跨操作者外部验证能直接说明工具的泛化能力。

**方案 C：时间外推验证（temporal validation）**

- **做法**：按检查日期前后切分（如 2024 年数据训练，2025 年数据测试）。
- **价值**：模拟"模型部署到未来"的真实场景，是临床 AI 论文的标准做法之一。

**方案 D：申请 DS-03/DS-04 数据集（做真正的外部验证）**

- **做法**：见 DS-03 的申请建议，联系上海大学/上海儿童医学中心团队。
- **价值**：**中国人群 + 中国设备 + 独立机构**，若能拿到，是最有说服力的外部验证，且可以直接和香港 PolyU 数据（DS-02）组成"多中心验证"。
- **风险**：周期不可控（2–6 周甚至更久），**不能把它写进不可变更的进度计划**，应作为"加分项"而非"关键路径"。

**方案 E：用 DS-02 做"切面级"外部验证（零风险，马上能做）**

- **做法**：用你们裁剪工具在 HK PolyU 的 50 张图上跑，检查：(1) 工具是否能正确裁出 ROI；(2) 工具判定的"标准/非标准"是否与 6 类人工标注方向一致。
- **价值**：Apache 2.0 许可无任何障碍，可写进论文并可公开代码。虽然只有 50 张，但作为**跨机构定性验证**是合法且诚实的。

**方案 F：人体阅片一致性对照（如有人工标注资源）**

- **做法**：对自采数据抽样，由 2 名 >5 年经验超声医师独立测量 α 角，计算 **ICC（组内相关系数）** 与 **Bland-Altman 一致性界限**，作为"人类水平"基线，报告你们的工具与人类的差距。
- **价值**：这是**没有公共数据集也能写出严谨验证**的标准路径——用"人类专家一致性"作为外部参照系，而不是"另一个数据集"。**强烈建议做这一项，成本低、说服力强。**

> **建议的外部验证章节写法**：
> "由于领域内无公开的婴儿 DDH 髋关节超声分类数据集（截至 2026-10，仅 2 个公开集，实测合计 85 张图，且均为切面质量/关键点标注，不含阳性/阴性诊断标签），本研究采用三层验证：(1) **跨设备外部验证**——设备 A 训练（n=__），设备 B 独立测试（n=__）；(2) **跨机构切面级验证**——在公开的 HK PolyU SPJ 数据集（n=50，Apache 2.0）上验证切面判定的一致性；(3) **人类水平对照**——2 名资深超声医师独立标注的 ICC 与 Bland-Altman 分析。此外，Radiopaedia 公开 DDH 超声病例（n=24 例，CC BY-NC-SA 3.0）用于 α/β 角测量的案例级目视核对。"

## 五、伦理与法律注意

### 5.1 公开数据的许可差异（必须逐条读懂）

| 许可 | 数据集 | 能商用 | 能改 | 需署名 | 需同协议开源 | 本项目风险 |
| --- | --- | --- | --- | --- | --- | --- |
| **Apache 2.0** | DS-02（HK PolyU） | ✅ 能 | ✅ 能 | ✅ 需 | ❌ 不需 | **最低**，放心用 |
| **CC BY 4.0** | MTDDH、AV-DDH、Mendeley DDH、DS-22b orvile | ✅ 能 | ✅ 能 | ✅ 需 | ❌ 不需 | **低**（但都是 X 光，用不上） |
| **CC BY-NC-SA 3.0** | **DS-01（Radiopaedia）** | ❌ **不能** | ✅ 能 | ✅ 需 | ✅ **必须** | **中**，可做学术验证，不可产品化 |
| **CC BY-NC 4.0** | FALLMUD | ❌ 不能 | ✅ 能 | ✅ 需 | ❌ 不需 | **中**，同上 |
| **Unknown（未声明）** | Kaggle `ddh-keypoint`、Nerve Segmentation、Fetal Head | ⚠️ **默认不可用** | ⚠️ | — | — | **高**，法律上等于"保留所有权利" |

**三个最容易踩的坑**：
1. **"Unknown" ≠ "免费"**。Kaggle 上未声明许可的数据集，按著作权法默认「保留所有权利」，**严格来说连下载后训练都有风险**。若要用，必须去原始来源（如比赛官网）找原始条款。
2. **"下载了" ≠ "有授权"**。GitHub 上仓库没有 LICENSE 文件，同样等于保留所有权利。`open-hip-dysplasia` 全库的 Zenodo 记录声明为 CC BY 4.0，但其内部各子集许可是不同的（Radiopaedia 是 NC、HK PolyU 是 Apache 2.0）——**必须按子集看，不能按全库看**。
3. **CC BY-NC 的"商业"边界**。参加**有奖金的竞赛**是否算商业使用？这是灰色地带。保守做法：若竞赛有现金奖励或商业转化条款，**不要用 NC 数据作为方法核心证据**；若纯学术、无奖金，通常可接受，但建议在论文中明确声明使用范围。

### 5.2 竞赛中使用的要求

- **绝大多数医学 AI 竞赛要求数据来源合法可追溯**。建议准备一张「数据来源台账」，逐条记录：数据集名、版本号、DOI/URL、获取日期、许可协议、使用范围、引用格式。**这既是合规要求，也是答辩时的加分材料。**
- **必须引用原始来源，不能只引聚合库**。用 Radiopaedia 病例要逐例引用（`Case courtesy of [Author] from Radiopaedia.org, rID [ID]`），不能写"数据来自 Open Hip Dysplasia Dataset"了事；用 HK PolyU 数据需引用原文 `Liu R, et al. NHBS-Net, IEEE TMI 2021;40(12):3446-3458`。
- **X 光数据集若使用必须说明"仅用于方法学对比，未参与超声模型训练"**，避免评委误以为你们把 X 光数据混进超声模型。
- **不要声称"在公开数据集上验证"**——若只用了 50 张视作定性核对，请诚实写"切面级一致性核对"，把主要指标放在自采的跨设备验证上。**诚实的方法学会加分，虚报的"外部验证"会被评为致命缺陷。**
- **代码与数据分离**：竞赛通常要求提交代码。只提交**代码 + 公开数据下载脚本**，不提交任何自采数据、不提交公开数据副本（尤其 NC 数据，SA 条款要求衍生作品同协议开源，容易牵连整个仓库）。

### 5.3 我们自己的数据为什么不能上传

**这是本项目最需要提前想清楚的一条伦理边界。** 你们自采的 DDH 超声数据**绝对不能**上传到 Kaggle / Hugging Face / 天池等公开平台，原因有三层：

**① 法律层面：伦理批件与知情同意不允许**

- 你们采集数据时，伦理批件（IRB）批准的用途通常是"用于本研究"。**超范围使用（含公开发布）属于违规**，医院可追究，个人可能面临学术不端认定。
- 婴儿数据需要**监护人签署知情同意**。绝大多数知情同意书里**没有"同意公开数据集"这一条**。就算有，婴儿监护人的同意在未来 18 年内还存在可撤回问题。
- 依据《中华人民共和国个人信息保护法》（PIPL）：14 岁以下未成年人的个人信息属于**敏感个人信息**，处理需取得监护人单独同意；健康医疗信息同属敏感个人信息。**公开数据集属于"向不特定对象提供"，是最严格的处理场景。**

**② 技术层面：超声图像"去标识"极难做到位**

- **烧录文字**：超声 DICOM 常把患者姓名缩写、检查日期、设备型号、探头参数**直接烧进像素**。你们的裁剪工具其实就在解决这个问题——但裁剪 ≠ 去标识，裁剪框外可能仍有残留。
- **DICOM 头**：设备序列号、检查号（Accession Number）、UID 都可能反推机构甚至个人。
- **准标识符组合**：**年龄（如"3 Days"）+ 性别 + 臀位 + 侧别 + 检查日期 + 医院**，这 6 个字段的组合在特定医院里高度唯一，足以定位到具体婴儿。Radiopaedia 的公开病例之所以能公开，是因为**由放射科医生逐例判断并取得授权**，且是**教学病例**而非连续筛查队列。
- **结论**：即使你不写姓名，把原始图直接传上网仍是高风险行为。

**③ 伦理与契约层面：对患者与医院的双重责任**

- **对患儿家庭**：DDH 影像虽不含面部，但公开后可能被用于训练商业模型、被二次识别、被不当传播。家长同意的是"治病"，不是"为开源做贡献"。
- **对医院**：数据产权通常归医院（或医院与研究者共有）。**未获医院书面许可即公开，属于侵占单位数据资产**，在多数高校/医院的管理办法中会被明确禁止，可能影响后续申报。
- **对领域**：一个不当公开的案例，可能让医院收紧所有后续研究的伦理审批，**损害后来者**。

**✅ 正确做法（做同样的事，但不越界）**：

| 想达到的目的 | 合规做法 |
| --- | --- |
| 展示代码与可复现性 | **公开代码 + 数据字典 + 标注规范 + 合成数据/示例图（人工绘制或彻底去标识后的 5–10 张）**，托管 GitHub 并打 Zenodo DOI |
| 让别人能验证方法 | 提供**标准化的评价脚本 + 指标定义 + 报告模板**，让第三方在自己的数据上复现 |
| 想为领域做贡献 | 走**受控共享**：写 Data Use Agreement（DUA），研究者签署后经伦理委员会审核批准再发放；或把数据托管在需要伦理审核的受控仓库（如 PhysioNet Credentialed Access 模式，见调研中 DSM 类数据集） |
| 参加竞赛需要数据 | 只向**主办方指定的评审环境**提交数据，不上公开网络 |

> **一句话给评委**：本项目自采数据受伦理批件与监护人知情同意约束，仅用于本研究，不会公开；我们以代码开源 + 跨设备验证 + 人类水平对照来保证可复现性，而非以公开患者影像来换取"数据量"。
