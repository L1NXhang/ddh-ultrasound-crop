## 四、关键否定性结论（同样有价值）

1. **Kaggle 无任何 DDH 超声数据集**（8 个关键词 API 检索），命中项全是 X 光或无关。
2. **Hugging Face 无髋关节/DDH 数据集**。
3. **PhysioNet / OpenNeuro / Zenodo / Dryad 均无人类 DDH 影像**
   （Dryad 命中的全是**犬类**髋关节发育不良 GWAS——兽医 CHD 是大坑，需逐条确认）。
4. 论文中的数据集**基本私有**：SCMC（上海儿童医学中心，700 张）+ APCH（安徽省儿童医院，1769 张）
   是目前最大规模，**完全不公开**。
5. → **结论**：不能指望公共数据做大样本外部验证，应走"跨设备切分 + 人类水平对照"路线。
