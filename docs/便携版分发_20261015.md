# DDH 裁剪工具便携分发版 v0.3.2

交付文件：`D:\ddhmodel\release\DDH裁剪工具_Windows_x64_CPU_v0.3.2.zip`，504,507,975 字节（约 481 MiB）。完整解压后运行 `DDH裁剪工具.exe`，图片和保存位置均可选择软件目录之外的文件夹。

这是软件打包分发，不需要为分发重新训练模型。[PyInstaller 的独立分发方式](https://pyinstaller.org/en/stable/operating-mode.html)将 Python 与运行依赖放入应用文件夹；本包使用 Windows x64 CPU 推理环境，接收者无需安装 Python 或准备独立显卡。

## 包内资产

- 原生 Windows 桌面外壳和内嵌裁剪界面。
- CPU 版 PyTorch 2.5.1、torchvision 0.20.1、Python 3.11 及必要依赖；CPU 组件来自 [PyTorch 官方版本说明](https://pytorch.org/get-started/previous-versions/)。
- 现有裁剪模型的推理参数。删除训练过程附带元信息，只保留 state、stage、size、baseline；导出前后所有参数逐项哈希一致。
- 微软 Fixed Version WebView2 155.0.4283.45，已校验微软签名，并包含读取权限准备逻辑。其分发和 Windows 10 权限要求按 [微软官方文档](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)实现。
- 第三方许可证、模型来源校验和全部文件的大小/SHA256 清单。

清单中没有 PNG/JPG/BMP、DICOM 或 JSONL 文件，也没有本机图片路径清单、审核记录、浏览器配置、项目数据和训练样本。模型权重属于要分发的算法资产，生产权重保持原样。

ZIP SHA256：`120ebf2ad658746da6533df78991e43fd365c00d0471993a10aefa6e8670e271`。

## 接收者怎么使用

1. 完整解压到本人可写的本地目录，再运行 EXE。
2. 选择图片目录和结果保存位置，建议都在软件文件夹之外。
3. 逐张审核时调整绿色框四边，Enter 确认保存；红框修改后按 R 重新预测。
4. P 查看成品预览，Ctrl+Z 撤销。正常关闭后可从相同目录组合恢复草稿。
5. 完成后按需生成结果 ZIP。人工确认记录可以单独交回负责人复核，软件不会自行训练或替换模型。

软件设置、日志和浏览器缓存位于包内 `ddh_multidevice_v2/data/studio_runtime`，因此需要完整移动整个软件目录。分发新的干净软件时使用原始 v0.3.2 ZIP，避免把实际工作后的缓存、路径或裁剪结果一起发送。

支持 Windows 10/11 64 位，系统需具备 .NET Framework 4.8。此包不适用于 macOS。工作区根目录原有 EXE 仍是本机 GPU 环境版本；不要将它单独发送给成员。
