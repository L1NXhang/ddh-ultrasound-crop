# 协作审核

这台电脑运行模型并保存图片与审核记录，组员使用浏览器登录，调整成像窗口和最终裁剪范围。只需要一个审核端口；桌面管理接口继续仅绑定本机回环地址。

## 主机操作

1. 关闭后重新打开 `D:\ddhmodel\DDH裁剪工具.exe`，选择图片文件夹和工作目录，使用逐张审核模式。
2. 点击右上角“协作审核”。设置组员账号与密码，账号使用字母、数字、下划线或短横线，密码至少 10 位。
3. 默认审核端口为 `8771`，可修改。监听地址可选所有局域网／组网接口，或只选某一个本机 IPv4 地址。
4. 点击“开启审核”。把相应的访问地址和各自的账号密码交给组员。
5. 设置面板显示每位组员的审核进度。点击“停止协作”会关闭审核端口并注销全部会话，已经保存的结果和草稿保留。

账号密码仅用于本次开启的协作会话。程序仅在内存中保存带随机盐的 PBKDF2 密码摘要，不把明文密码写入项目文件。停止协作或退出软件后，需要重新设置账号密码。浏览器登录有效期为 8 小时。

当前文件夹中，已确认图片和本机未确认草稿不会分给组员。首次分配按账号均分；重新开启时保留仍在名单中的账号与未完成图片的归属，避免已保存草稿被分给其他人。更换账号名单时，离开账号的未完成任务可以重新分配；其旧草稿会保留在磁盘，需负责人决定是否采用。

协作开启期间不能切换项目或开始自动批量裁剪。已分配图片的本机编辑也会被拒绝，避免主机与组员互相覆盖。需要负责人接管时，先停止协作。

## 组员操作

1. 在浏览器打开负责人给出的地址，输入各自账号密码。
2. 红框是完整成像窗口，绿框是最终裁剪范围。拖动绿框四边，保留需要的图像，排除边缘图标或文字。
3. 如果红框不对，按 `W` 调整窗口，再按 `R` 让主机按新窗口重新预测；按 `C` 回到裁剪范围。
4. `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做，`P` 查看成品预览。
5. 调整会保存到主机的个人草稿。确认后按 `Enter` 或“保存并下一张”，裁剪图片和审核 JSON 直接保存在主机。
6. 不确定的图片按 `K` 稍后处理，可以从“全部”队列再次进入。结束时点击“退出登录”。

组员不能选择主机目录、读取其他账号的图片、下载项目压缩包、启动批量处理、管理协作服务或启动训练。浏览器会收到当前分配图片的图像内容用于显示，因此授权成员仍可截图；这一功能不提供防截图或禁止另存的承诺。

如果同一账号在另一个页面打开了同一张图片，旧页面的保存会被版本令牌拒绝。出现冲突提示时刷新页面，检查主机已保存内容后继续，系统不会自动覆盖较新的审核记录。

## 局域网连接

双方连接同一可信局域网后，组员使用设置面板显示的 `http://主机局域网IP:8771`。

- `127.0.0.1` 和 `localhost` 只在主机本身有效，不能发给组员当作访问地址。
- Windows 防火墙需要允许对应审核端口的入站访问，范围限制为所在局域网或具体组员 IP。本次代码改动没有自动修改系统防火墙。
- 公共 Wi-Fi 可能隔离设备；仅连接同一个 Wi-Fi 名称不保证互相可达。
- 局域网 HTTP 本身不加密密码与图像，只在可信网络内使用；需要加密时使用下述组网或 HTTPS 方式。

## 外网连接

软件提供两种接入方式，不会仅凭设置一个端口就自动获得公网可达性。

### 加密组网

主机与组员配置 Tailscale 等加密组网后，可使用主机的组网 IPv4 地址加审核端口访问。主机只选择组网接口监听时，同一服务只在该接口提供访问。软件识别并列出本机的局域网和 `100.64.0.0/10` 范围组网地址。

组员无需安装本软件、Python、模型或 CUDA；采用这一方式时需安装和登录组网客户端。主机的组网权限应只允许受邀成员访问审核端口。设置组网和邀请成员需由负责人完成，本次没有创建第三方账户、发送邀请或安装组网工具。

官方说明：[共享单台设备](https://tailscale.com/docs/features/sharing)、[从外网访问本机服务](https://tailscale.com/docs/use-cases/personal-or-at-home-use/access-nas-media-file-servers?tab=windows)。

### HTTPS 代理，组员只用浏览器

如果已有域名和可达的 HTTPS 代理，在“外网连接”中填写 HTTPS 根地址，例如 `https://review.example.com`。代理转发到审核端口并保留原始 `Host` 和 `Origin`；不要代理桌面的管理端口。

同机 Caddy 配置示例：

```caddyfile
review.example.com {
    reverse_proxy 127.0.0.1:8771
}
```

这里的域名需要替换成实际域名，DNS、证书、代理和网络路由必须另行配置。该示例没有被自动部署到本机或服务器。代理位于另一台机器时，需要它通过可信私网／组网访问主机的审核接口，不能把未加密的上游 HTTP 穿过公网。

HTTPS 地址登录会设置 `Secure`、`HttpOnly`、`SameSite=Strict` Cookie；写入请求还检查来源与会话 CSRF 令牌。直接来自公网地址的 HTTP 客户端会被拒绝。审核服务是面向小团队的受限服务，公网入口应由 HTTPS 代理承担，而不直接暴露 Python HTTP 服务。

官方说明：[Caddy 反向代理](https://caddyserver.com/docs/caddyfile/directives/reverse_proxy)、[Python HTTP 服务的部署限制](https://docs.python.org/3.11/library/http.server.html)、[会话保护](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)。

## 数据保存

文件仍在所选工作目录内的 `DDH裁剪结果\项目名_标识\`：

| 文件或目录 | 内容 |
|---|---|
| `cropped\` | 确认后的裁剪图片 |
| `annotated\` | 成像窗口与最终裁剪范围标线图 |
| `review_history.jsonl` | 逐次确认的历史版本与审核账号 |
| `results.jsonl` | 每张图片最新的保存结果 |
| `reviewed_training_candidates.jsonl` | 人工确认的训练候选，保留审核人 |
| `remote_drafts\账号\` | 未确认的个人草稿，重启后可恢复 |
| `collaboration\` | 任务分配记录与会话编号，不含密码 |

坐标均为原图像素中的半开区间 `xyxy`。审核记录保留原始预测、重新预测、最终裁剪框、原图 SHA256、模型 SHA256 和审核人。人工确认的记录仍是候选，`approved_for_training` 保持 `false`；不会把未确认草稿或未经审核的自动结果直接变成训练标签，也不会自动训练或替换模型。

主机需要保持开机、软件运行和网络连通。电脑休眠或关机会中断连接，已经写入磁盘的草稿与确认记录不会因此丢失；请留意浏览器上的草稿保存状态。
