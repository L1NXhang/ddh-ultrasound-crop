# 安装与分发

## 下载

进入 [GitHub Releases](https://github.com/L1NXhang/ddh-ultrasound-crop/releases/latest)。普通电脑选择 CPU 安装包；希望使用兼容 NVIDIA CUDA 显卡加速时选择 CPU/GPU 自动版。

| 文件 | 怎样使用 |
|---|---|
| `DDH_Crop_Setup_0.5.1_CPU_x64.exe` | 完整 CPU 安装程序，单个文件即可分发 |
| `DDH_Crop_Setup_0.5.1_CPU_GPU_x64.exe` | 完整 CPU/GPU 自动版安装程序，单个文件即可分发 |
| `SHA256SUMS.txt` | 下载文件的 SHA256 校验清单 |

GitHub 自动生成的 Source code ZIP 是源码，不包含推理环境、模型和浏览器运行时，不能代替安装包。

GitHub 每个发行附件必须小于 2 GiB。本次通过安装器的 LZMA2 压缩，CPU 和 GPU 安装包都满足这一限制，均可单文件下载。参考 [GitHub 发行版限制](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)。

## 安装

1. 下载 CPU 或 GPU 安装 EXE。两种版本都只需要一个安装文件。
2. 双击 `DDH_Crop_Setup_...exe`，选择本人可写的安装位置，按安装向导完成。
3. 从开始菜单打开 DDH 图像裁剪，也可以在安装时选择创建桌面快捷方式。
4. 选择自己的图片文件夹和工作目录。图片和结果建议放在软件目录之外。

支持 Windows 10/11 64 位和 .NET Framework 4.8。安装器默认只安装到当前用户目录，不请求管理员权限。软件包含 Python、推理模型及 WebView2，不要求另装 Python、独立显卡或 CUDA 工具包；使用 GPU 仍需兼容的 NVIDIA 显卡与驱动。

目前安装器没有项目自己的代码签名证书，Windows 可能显示未知发布者。请确认来源为本仓库的 Releases，必要时核对 SHA256，不通过关闭安全软件来处理安装问题。

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath .\DDH_Crop_Setup_0.5.1_CPU_x64.exe
```

CPU 和 CPU/GPU 安装到不同目录。升级前关闭正在运行的对应软件，再安装新版本。

## 哪个 EXE 可以单独发

应用目录中的 `DDH裁剪工具.exe` 只是启动入口，依赖旁边的 `ddh_multidevice_v2` 目录。它不能独立分发。

CPU 安装程序 `DDH_Crop_Setup_...CPU_x64.exe` 内含完整文件，可以单独发给别人。本次 GPU 安装程序也包含完整文件，可以单独分发。

## 更新与卸载

v0.5.1默认不再额外外扩2%，人工确认框直接作为最终框标签；旧结果与草稿不自动重算。旧图需要新预测时按R重新预测并确认。

安装新版本之前关闭软件。同一安装类型的新版本覆盖应用文件；CPU 与 CPU/GPU 使用独立安装目录和卸载项。

可在 Windows 的“已安装的应用／应用和功能”中卸载。安装器只删除其安装的程序文件，不主动删除用户选择的图片目录、裁剪结果、审核记录或运行后生成的个人数据。重要结果仍建议自行备份。

设置和浏览器缓存保存在应用子目录 `ddh_multidevice_v2/data/studio_runtime`。若需要彻底移除剩余设置，应先确认其中没有需要保留的信息，再自行处理。

## 只帮忙标注

组员通过主机的协作审核网页登录时，无需下载安装本软件。负责人开机并运行软件，开启协作、分配账号即可。外网仍需要配置组网或 HTTPS 代理，见[协作审核使用说明](协作审核使用说明_20261015.md)。
