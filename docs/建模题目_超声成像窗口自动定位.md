# 建模题目：超声截图成像窗口的自动定位与可靠拒绝

（可直接提交给求解方；所有数字均来自真实项目实测）

---

## 0. 一句话问题

给一张从**未见过的超声设备**导出的截图，自动找出其中的**成像窗口矩形**（本文简称"红框"），
并在没有把握时**明确拒绝**而不是给一个错的框。要求正确率尽可能高，且**静默错误率趋近于 0**。

---

## 1. 背景与任务定位

本项目要训练一个 DDH（发育性髋关节发育不良）超声自动裁剪模型。裁剪只做**上下方向**，
而裁剪的宽度被定义为**成像窗口的宽度**。因此整条流水线的第一步是：

> 在原截图中定位"成像窗口"——即真正承载超声回声的那块矩形区域，
> 把窗口外的黑边和界面元素（参数文字、深度刻度、人体示意图、品牌 logo、进度条、缩略图）排除掉。

这一步的结果既用于**生成训练标签**（每张图必须有一个窗口框），
也用于**产品推理**（步骤 A 需要自己找到窗口）。本文只讨论第一步。

---

## 2. 核心问题（问题一）

**如何实现最高的识别率，来正确标出这个红框？**

形式化：给定图像 $I \in \mathbb{R}^{H\times W\times 3}$，输出

$$
A(I) \in \{(x_0,y_0,x_1,y_1)\} \ \cup\ \{\bot\}
$$

其中 $\bot$ 表示"拒绝（无法确定，交人工）"。评价不是单看平均误差，而是：

> **在保证"输出即正确"的前提下，把拒绝率压到最低。**

---

## 3. 求解目标（问题二）

**有没有好的自适应算法？** 具体要满足：

1. **跨设备自适应**：面对完全没见过的设备/分辨率/界面布局，不需要重新写规则；
2. **批内自组织**：对一批来自同一台设备的图，能自动发现"这是同一种布局"，
   并给出该类布局的窗口框；
3. **拒识优先**：认不出来就拒绝。人工介入成本应与**布局类数**成正比，而不是与图像数成正比；
4. **可验证**：每个输出附带经过标定的置信度，能在留出集上算出覆盖率与静默错误率。

---

## 4. 观测模型（形式化描述）

把截图视作四类成分的叠加：

$$
I = \underbrace{B}_{\text{黑边}} + \underbrace{W}_{\text{成像区}} + \underbrace{O}_{\text{窗口内叠加}} + \underbrace{C}_{\text{窗口外界面元素}}
$$

| 成分 | 统计特征 | 说明 |
|---|---|---|
| $B$ 黑边 | 灰度 $\approx 0$，含 JPEG 压缩噪声 | 截图四周的大片纯黑 |
| $W$ 成像区 | 斑点噪声，**局部均值可为任意值**（深部/无回声区可能接近 0） | 我们要找的矩形 |
| $O$ 窗口内叠加 | 稀疏亮笔画 | 测量线、卡尺、角度标注、距离标注 |
| $C$ 窗口外界面元素 | 稀疏亮笔画或小色块 | 文字、刻度点、人体图、logo、进度条、缩略图 |

**关键难点（必须在方法里处理）**：
- $W$ 内部存在**接近黑**的区域（无回声/深部），所以**亮度阈值无法定义窗口**；
- $C$ 中存在**亮**的笔画（白字、白刻度），所以"亮 = 属于窗口"也不成立；
- 因此判别量必须是**密度与结构**（见 §6），而不是亮度。

**假设**：窗口是**轴对齐矩形**；一张图通常只有一个窗口。若出现**多窗口**（双屏、四宫格）
或**非矩形视场**（扇扫/梯形），允许直接拒绝，不允许猜。

## 5. 数据与先验（这是本题最重要的"抓手"）

### 5.1 数据现状（真实、已清点）

| 集合 | 数量 | 说明 |
|---|---|---|
| 主数据集 | 1080 张 | 5 个来源文件夹（余 230 / 吴 200 / 张 230 / 胡 157 / 阳 263） |
| 分辨率分布 | 1280×960：989；1024×768：44；1292×970：43；1552×970：4 | 分辨率**是弱特征**（新旧批次会撞） |
| 设备品牌 | 1280×960 → Philips（Precision+/Pure+，i11LX3 探头）；1292×970 → GE LOGIQ；新批次 1260×910 → Mindray Resona 7；1024×768 → 未识别 | 至少 4 种界面 |
| 新数据集 | 874 张 | 来自**未见过的设备**，文件名是 DICOM 编号，规格 1260×910 与 1024×768 |
| **已确认窗口标签** | **869 张** | 1280×960 主布局，人工确认 |
| **难例集（待人工）** | **211 张** | 窗口与主布局不同（见 §5.3） |
| 人工裁切图 | 1072 张 | 人工裁出的成品图，**宽度 = 窗口宽度**（见 §5.4） |

### 5.2 已确认的先验（可直接用）

1. **同一（设备，视口）下，窗口框是一个常量。**
   实测：1280×960 主布局的窗口为

   $$
   B^\* = (x_0,y_0,x_1,y_1) = (368,\ 136,\ 912,\ 744)
   $$

   即 $544\times608$ 像素，占画面 $42.5\%\times 63.3\%$。
   左右外边距**完全对称**（各 $368$ px，即 $28.75\%$），可作"水平居中"先验。
2. **界面外壳（窗口之外的区域）在同布局下几乎逐像素相同**——可作为**布局指纹**，
   用于自动判定"这张图属于哪一类布局"。这比分辨率可靠得多。
3. 人工裁切图的**水平范围 ≈ 窗口的水平范围**，
   实测 1072 张中"裁切宽度与窗口宽度差 ≤12px"的比例为 **100%**。
   → 这是一个**免费的弱标签**：给出了窗口的水平边界（$\pm12$ px），但**给不出垂直边界**。

### 5.3 已知的困难例（211 张，占 19.5%）

在 989 张 1280×960 中，有 **120 张**的窗口与 $B^\*$ **确实不同**：
例如某张 1280×960 图的内容从 $x=337$ 开始（比 368 左移 30 px），
该图右下深度标尺止于 4.5 而非常见的 5（扫描深度不同）。
验证方式：像素剖面（行均值从 $x=360$ 的 $0.3$ 跳到 $x=380$ 的 $30.0$）。

另有 44 张 1024×768、43 张 1292×970、4 张 1552×970 的布局与主布局不同。

**这 211 张是最能区分算法好坏的测试集**：它们要么被正确定位，要么被拒绝——
绝不允许被"勉强套上主布局的框"。

### 5.4 可作为半监督信号的数据

- 869 张已确认框 → 有监督；
- 1072 张人工裁切图的水平范围 → 弱监督（水平边界）；
- 874 张新设备图 → **完全没有标签**，用于检验零样本自适应能力。

## 6. 判别量的设计（提示，不是限定）

朴素做法（已被证明不足）：对每列/每行计算"非黑像素占比"，取连续超阈值的区间当作窗口。

实测该做法的表现：
- 逐图独立检测与确认框在 $\pm8$ px 内的一致率仅 **20%–40%**；
- 失手两个方向：
  - **收边**：成像区边缘为低回声暗区 → 该列密度掉到阈值下 → 框变小（甚至锁到一条竖亮带）；
  - **扩边**：窗口外白字/刻度/进度条 → 外侧密度被抬高 → 框变大或选错边。

可行的判别特征（提示）：
密度（occupancy）、沿垂直方向的**长直线一致性**、梯度能量沿直线的积分、
**变点检测**（把列剖面看作分段常量信号，用带惩罚的最优分段求边界）、
纹理能量（成像区是稠密斑点，文字是稀疏笔画）。

**双向校验**（建议作为必备机制）：
- 框内必须有内容（防框过小）；
- 框外一圈条带必须干净（防框过大）。
  实测判据：框外 8 px 条带中"亮像素占比 ≤ 0.10"时，869/989 张通过。

**跨图共识**（建议作为必备机制）：同布局多图取众数/中位数，偏离者标记为待人工。

## 7. 评价指标（严格定义，必须全部报告）

设测试集 $N$ 张，容差 $\tau$（建议 $\tau=4$ px @1280×960，按短边等比缩放），
对每张图定义四边最大误差 $\Delta_i$；算法输出框则判定对/错，输出 $\bot$ 则记拒绝。

| 指标 | 定义 | 目标 |
|---|---|---|
| 覆盖率 $C$ | 非拒绝数 / $N$ | 越高越好 |
| **静默错误率 $S$** | （输出且 $\Delta_i>\tau$）的数量 / $N$ | **主指标，目标 $S=0$（或 $\le 0.5\%$）** |
| 精度 $P$ | 输出中 $\Delta_i\le\tau$ 的比例 | $\to 1$ |
| 拒绝率 $R$ | $1-C$ | 已知布局上应低，新布局上允许高 |
| **布局发现成本 $M$** | 每出现一种新布局，需要人工确认的次数 | 越小越好（理想 = 1 次/布局） |
| 边缘误差分布 | 分位数（50/90/95/100%）与最大值 | 报告全分布，不看平均 |
| 分层报告 | 按设备 / 分辨率 / 来源分别报告上述指标 | **强制**，禁止用平均值掩盖某台设备全错 |

**目标函数形式（建议）**：

$$
\min\ \ \alpha S \;+\; \beta(1-C) \;+\; \gamma M
\qquad \text{s.t.}\quad S \le \varepsilon
$$

$\varepsilon$ 取 0 或极小值；$\gamma$ 反映人工成本。**不允许**用"平均 IoU 高"来掩盖若干张全错。

## 8. 约束与红线

1. **禁止静默错误**：宁可拒绝。输出错框但未报警 = 最严重失败。
2. **禁止用测试集调参**；训练/开发与测试必须按**设备或来源**划分（防泄漏）。
3. **禁止利用文件名、图像编号、分辨率作为标签泄露**（分辨率是弱特征，可作特征但不可当作答案）。
4. **禁止人工逐图修正测试集结果**；只允许在"人工确认框"这一环节介入。
5. **禁止生成式修复/擦除窗口内叠加**（测量线、文字）——会改变解剖信号。
6. 多窗口/非矩形视场可以拒绝，**不许猜**。
7. 方法必须能在**无标签批次**上运行（不能要求先有该设备的标注）。

## 9. 交付物

1. 形式化模型 + 算法伪代码（含拒绝判据）；
2. 超参数如何确定：优先**自校准/无监督**（如从当批数据估计阈值），若必须人工设定需给出敏感性分析；
3. 复杂度分析（1080 张、10 万张、以及单卡推理时的可行性）；
4. 在三个集合上的分层评估结果：**869 张已确认集 / 211 张难例集 / 874 张新设备集**；
5. 失败案例分析：哪类图会错、错多少像素、为什么，以及被拒绝时的理由是否合理；
6. （加分）跨设备零样本能力、增量学习（新设备确认一次后自动吸收）、
   置信度的**校准度**（预测"我很有把握"时是否真的对）、不确定性度量。

## 11. 评分维度（建议）

| 维度 | 权重 | 说明 |
|---|---|---|
| 静默错误率 $S$ | 最高 | 在难例集与新设备集上是否为 0 |
| 覆盖率 $C$（已知布局） | 高 | 869 张上应接近 100% |
| 新布局的自适应能力 | 高 | 874 张上：正确 + 正确拒绝是否覆盖全部，无静默错 |
| 布局发现成本 $M$ | 中 | 每类是否只需 1 次人工确认 |
| 方法的可复现与可解释 | 中 | 超参是否自校准、判据是否可解释 |
| 计算成本 | 低 | 1080 张批量运行的耗时 |
