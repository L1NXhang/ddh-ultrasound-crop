## 2 现在就能做：三条命令跑通训练

```bat
cd /d D:\ddhmodel\ddh_multidevice_v2
.venv\Scripts\activate

python ddh.py audit --manifest data/pilot.jsonl --root data --output data/reports/grouped.jsonl --report data/reports/pairs.json
python ddh.py split --manifest data/reports/grouped.jsonl --output data/reports/split.jsonl --reviewed --seed 42
python ddh.py train --stage window --manifest data/reports/split.jsonl --root data --output runs/window.pt --size 640 --batch 2 --epochs 40 --patience 8 --device cuda
python ddh.py train --stage crop   --manifest data/reports/split.jsonl --root data --output runs/crop.pt   --size 384 --batch 8 --epochs 80 --patience 12 --device cuda
python ddh.py evaluate --manifest data/reports/split.jsonl --root data --window-checkpoint runs/window.pt --crop-checkpoint runs/crop.pt --output runs/test.json --device cuda
```

（前两条我已实测跑通：`train 126 / val 29 / calib 19 / test 21`。训练两条预计各 0.5–1 小时。）

## 4 你可能会遇到的报错

| 报错 | 原因 | 怎么办 |
| --- | --- | --- |
| `TypeError: cannot unpack non-iterable NoneType object` | 清单里有 `window: null` 的行 | 用 `--subset window,crop` 生成齐备子集，或补齐那 211 张 |
| `At least 10 non-held-out groups required` | `audit` 把图并成了很少的组 | 检查是不是把文件夹名填进了 `source_group`（见第 6 节） |
| `Validation requires positive quality and expert safe_box labels` | 没有 safe_box/quality | 校准需要它们；先只用 train/evaluate |
| 训练很慢 | GPU 没被用上 | 加 `--device cuda`，并用 `python -c "import torch;print(torch.cuda.is_available())"` 确认 |

## 6 两个容易搞错的字段

| 字段 | 含义 | 现在怎么填 |
| --- | --- | --- |
| `collect_group` | **采集来源**（余/吴/张/胡/阳 文件夹） | 已自动填好 |
| `source_group` | **同一序列 / 同一批次**（同一次检查的多张图） | 留空，除非你确知某几张是同一次检查 |

`ddh.py audit` 会把同一个 `source_group` 的图并进同一个泄漏组。拿文件夹当 `source_group`
会让整批并成一组、`split` 直接报错（这个坑我踩过并修掉了：修正前 195 张并成 1 组，修正后 195 组）。
