## 二、数据与坐标：一切以原图像素为准

**原理**：标签坐标系必须唯一且不随流程变化。若用归一化坐标，遇到不同分辨率、不同裁剪就互相污染。
所以 JSONL 里的 `window / crop / safe_box` **全部是原截图像素**，右/下边界不含端点。

**letterbox（`ddh.py:157`）**：把窗口区域**等比缩放 + 居中填充**到 384×384，而不是拉伸成正方形。

- 拉伸会改变解剖比例，模型学到的是变形后的几何，等于人为制造域偏移；
- letterbox 保持比例，代价是出现填充带——所以代码额外返回 `roi`（真实内容在画布上的四边），
  用 **ROIAlign** 只在真实内容区采样（`ddh.py:216`），让填充宽度不参与决策。

## 三、步骤 A：单类别目标检测

**用什么**：Faster R-CNN + MobileNetV3-Large + FPN，COCO 预训练，把最后的分类器改成"背景/窗口"两类（`ddh.py:245`）。

**原理**（三代经典结构）：
1. **RPN**（区域提议网络）在特征图上生成候选框，并判断"这里面有没有东西"；
2. **ROI 头**把候选框的特征池化成固定大小，做分类 + 边框回归；
3. **NMS**（非极大值抑制）压掉重叠框。

FPN 的作用是融合不同尺度的特征——超声窗口在不同设备上大小差很多，多尺度特征让同一个模型都能覆盖。

**决策规则**（`ddh.py:271`）：分数 ≥0.8 的框**必须恰好一个**，否则拒绝。
"恰好一个"这条很关键：双屏、四宫格、拼图一律不猜，直接交人工。

**为什么不用"非黑像素外接框"**：窗口外的参数文字、刻度、人体示意都是亮像素，
窗口内又可能有接近全黑的无回声区——**亮度无法定义窗口**（原方案文档的原话，我实测也印证了：
逐图阈值检测与人工确认框的一致率只有 20%–40%）。

## 四、步骤 B：有序坐标参数化（整套代码里最核心的设计）

**要解决的问题**：直接回归两个数（上边界、下边界）会有两个毛病——
① 可能输出"上边界 > 下边界"的非法结果；② 两个独立的头会互相穿越。

**解法**（`ddh.py:189`）：不让模型直接回归坐标，而是预测**三个间隔**：

```
上空白  |  保留区（要裁出来的部分）  |  下空白
   p0               p1                    p2
```

对三个 logits 做 softmax（自动归一化到总和为 1），再加一个极小的正下限 ε：

$$p_i=(1-3\epsilon)\mathrm{softmax}(z)_i+\epsilon,\qquad \epsilon=10^{-4}$$

然后 $r_t=p_0$，$r_b=p_0+p_1$。

**为什么这样就对了**：$r_t$ 与 $r_b$ 是同一组非负数**累加**出来的，数学上天然满足
$0\le r_t<r_b\le1$——上边界永远小于下边界、永远落在窗口内、永远不会被交换。
不需要训练后排序，也不需要额外约束项。

**ε 的作用**：softmax 在极端 logits 下会下溢到 0，导致上下边界重合（零高度裁剪）。
加 ε 让最小值有正下限，训练早期也不会出现退化解。

## 五、空间头：为什么推荐模型不用全局池化

**基线（`--baseline`）**：ResNet18 → 全局平均池化得 512 维 → MLP → 3 个间隔。
它知道"整张图大概像什么"，但**不知道"边界在第几行"**——因为全局池化把纵向位置信息压掉了。

**推荐模型**（`ddh.py:211-218`）：
1. 取 ResNet18 的 **layer3**（步长 16）特征图；
2. 用 **ROIAlign** 取回真实内容区，输出 24×16（高×宽）；
3. 沿**水平方向**分别做 mean 和 max，拼成 128×24 —— 相当于"把每一行压成一个 128 维的行向量"；
4. 用两层 **1D 卷积**（kernel=3）沿**垂直方向**卷积，保留纵向位置与邻域关系；
5. 展平 768 维 → 128 → 3 个间隔。

**原理**：这本质是一个"**行分类器**"。第 3 步让每个纵向位置得到一个特征；
第 4 步的 1D 卷积让相邻行之间互相"看见"，因此能判断"边界大概在第几行"。
max 保留该行最强的响应，mean 给出该行的整体统计——两者互补。

## 六、两个辅助任务

| 头 | 输入 | 预测什么 | 为什么需要 |
| --- | --- | --- | --- |
| `safe_head` | 共享 768 维行特征 | 专家 safe_box 的纵向范围 | 主监督只表达"人偏爱怎么裁"，**无法表达"哪些结构不可缺失"** |
| `quality_head` | 512 维全局特征 | 这张图能否给自动建议（BCE） | "该不该给建议"是独立于裁剪精度的判断 |

**缺标签怎么办**：每一项损失都有布尔 mask，只在有标签的样本上求均值（`ddh.py:229`），
**不把"没标注"当成负例**。这条很关键——否则等于教模型"没标注的东西不存在"。

---

## 七、损失函数（`ddh.py:229`）

$$L=L_{reg}+0.25\,L_{IoU}+2\,L_{keep}+0.25\,L_{safe}+0.25\,L_{quality}$$

| 项 | 实现 | 直觉 |
| --- | --- | --- |
| $L_{reg}$ | 归一化坐标上的 Smooth L1，beta=0.02 | 对像素级误差敏感，beta 让小误差区近似 L2、大误差区近似 L1 |
| $L_{IoU}$ | 1 − 一维区间 IoU | 直接优化"区间重叠"，比逐点误差更贴合任务 |
| $L_{keep}$ | **单侧** ReLU：$\max(r_t-s_t,0)+\max(s_b-r_b,0)$ | **只惩罚"裁进安全包络"，不惩罚外扩** |
| $L_{safe}$ | 安全头自己的 Smooth L1 | 辅助监督 |
| $L_{quality}$ | BCE | 二分类 |

**$L_{keep}$ 为什么是单侧**：这是整套设计的价值取向——保守的宽裁剪不伤害病人，
漏掉结构才伤害。把"外扩"和"内切"当成同等错误，会把模型推向危险的中间解。

## 八、训练循环里五个讲究的工程细节

1. **差分学习率**（`ddh.py:295`）：主干 3e-5、其余 3e-4。
   预训练主干已经很好，大学习率会摧毁它；新初始化的头需要大学习率才能动起来。
2. **冻结 BatchNorm 的运行统计量**（`ddh.py:205`）：小样本 + 近重复数据下，
   batch 统计量噪声大且彼此相关，用预训练的均值/方差更稳（BN 的仿射参数仍然训练）。
   这是我读原代码时觉得最讲究的一处。
3. **按相似组逆频率采样**（`ddh.py:291`）：按 `leak_group` 的逆频率加权，
   避免某个大同源序列主导梯度。注意是按**组**加权而不是按类别——更贴合"同源图片相关"的现实。
4. **选点只看验证集**：步骤 A 按平均 (1−IoU) 选，**漏检计 0 分而不是丢弃**（否则模型学会"少检测"）；
   步骤 B 按带 mask 的复合验证损失选。
5. **余弦退火 + 梯度裁剪（norm 5）+ 早停**：标准配方，稳定小样本训练。

## 九、推理侧：三道不确定性 + 默认拒绝

| 机制 | 实现 | 原理 |
| --- | --- | --- |
| **模型分歧** | MC Dropout：只把裁剪头的 Dropout 打开、BN 保持 eval，前向 16 次，取上下边界标准差的最大值（`ddh.py:343`） | 真贝叶斯推理太贵，用"随机失活下的输出抖动"廉价近似"模型有多犹豫" |
| **切面可用性** | 温度缩放：在 val 上用 BCE 拟合一个 T，输出 sigmoid(logit/T)（`ddh.py:391`） | 神经网络的概率通常过度自信，温度缩放是最简校准方法 |
| **域偏移** | 训练集 L2 归一化 512 维特征做参考库，最近邻欧氏距离（`ddh.py:441`） | 新设备/新界面的特征会"离群"，距离可以直接当 OOD 信号 |

**门控（`ddh.py:400`）**：上面任一项不过、或界面样式未知、或没有校准文件 → 一律
`review_required=true`。**默认拒绝**是这套代码的哲学：宁可多交人工，不给可疑建议。

## 十、校准的统计：Clopper–Pearson 上界（`ddh.py:378`）

在独立 calib 集上按**相似组**统计失败，用精确二项分布上界（自己实现，避免引入 scipy）：

$$U_{95}=1-0.05^{1/n}\quad(\text{零失败 } k=0)$$

所以：30 组零失败 → 上界 9.5%，**过不了 5% 的门槛**；59 组零失败才刚好低于 5%。

**原理**：这不是"我一次都没错"这种话，而是"在零错误的观测下，真实错误率最高可能是多少"的
统计置信上界。方案文档也明确写了：由于患者独立性无法验证，这个上界只能叫**名义统计核查**。

## 十一、我加的那些工具，原理是什么

| 工具 | 技术 | 原理 |
| --- | --- | --- |
| 窗口模板 + 条带判据 | 统计共识 | 同一台机器的窗口是常量；"框外一圈必须干净"是**必要**条件，用它把"能套用"和"要人工"分开 |
| 裁切图反推 | **FFT 互相关求 SSD 曲面** | 全图模板匹配放到频域做，复杂度 O(N log N)；再用"峰值突出度 =（次优 − 最优）/ 模板能量"判断匹配是否唯一 |
| 多尺度搜索 | 缩放金字塔 | 应对"裁切时被缩放过"的情况：1.0 优先，残差大再扫其他尺度 |
| 标注工具 | 标准库 http.server + canvas | 模型与人工在同一界面闭环，每张记录"模型预测 vs 人工最终"，直接产出训练标签与评估指标 |

## 十二、几个"为什么不用别的方案"

| 备选方案 | 为什么没采用 |
| --- | --- |
| 全像素分割 | 标注成本高、现有标签不支持；窗口是矩形，框标注足够 |
| 圆/椭圆拟合视场 | 与实际"全宽矩形裁剪"的操作不一致，还会去掉测量参照结构 |
| 按 Graf 分型拆多个模型 | 总共才一千多张，拆分会稀释样本、罕见类型过拟合，且路由错误会传播成裁剪错误 |
| 两阶段端到端联合微调 | 方案文档明确说"脆弱"；分开训练更可控、可单独评估 |
| 亮度阈值定窗口 | 窗口外有亮文字、窗口内有黑区，亮度不能定义窗口（已实测失败） |
| 用测试集调阈值 | 一律禁止；阈值只在 val 上定、在 calib 上核查 |

## 十三、一句话总结

这套代码的设计哲学可以概括成三句：

1. **输出必须合法**——用有序参数化把"上<下"变成数学性质，而不是靠惩罚项去"求"；
2. **缺失不是负例**——所有监督项都带 mask，没标注就不参与，不教模型错误的知识；
3. **默认拒绝**——所有不确定性（分歧、质控、域偏移、校准不足）都收敛到"交人工"，
   因为在这个任务里，**静默的错误比明显的拒绝贵得多**。
