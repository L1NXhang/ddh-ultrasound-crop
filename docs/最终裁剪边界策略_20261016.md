# 最终裁剪边界策略（v0.5.1）

模型默认直接输出最终裁剪线，不再自动向上、向下各扩窗口高度的2%。原图坐标换算及向外取整保留，用来确定整数像素边界；不会再加固定像素边距。

## 标注、训练、预测采用同一含义

- 人工保存的 `clean_box` 就是最终保留矩形，训练上下标签取其 top、bottom。
- 数据读取只换算为窗口内归一化坐标，不根据当时的模型外扩比例缩回或扩张标签。
- 模型默认 `margin=0`，预测直接映射回原图；研究校准入口也默认0。
- 新训练候选记录 `label_semantics=final_crop_box`；模型来源记录 `crop_policy=final_bounds/v1` 和实际 `margin`。
- 训练损失中的容差、Smooth L1参数及评估容差不等于输出外扩；这些数值没有因本次修复改成0。

已人工确认的数据仍然有效，不把过去的框自动缩回2%。未审核的自动裁剪不视为人工真值；软件仍不自动训练或批准标签。

## 旧任务与显式外扩

旧结果、已确认框和未确认草稿原样保留。打开旧任务会恢复原有内容，不在后台重新裁剪。需要使用新策略生成建议时，按R重新预测，再自行确认。

桌面源码入口和旧裁剪命令行入口默认不扩边。确有实验需要时，可以显式传 `--margin 0.02`，记录实际使用的比例；加载旧的显式校准文件时仍尊重其中的margin，避免改变历史复现条件。

修改源代码不会改变已经冻结在v0.5.0安装包里的后端。开发目录的程序关闭重开后生效；其他电脑应安装v0.5.1新包。已发布的v0.5.0不会自动更新。

## 验证及范围

回归检查覆盖：默认不扩边、显式外扩和边界截断、非法比例拒绝、桌面与旧CLI默认一致、研究入口默认一致、训练标签不随旧模型margin变化，以及旧确认结果反复恢复后坐标不漂移。

本次保留原有生产权重，未启用本轮尚未通过验收的候选模型。这里修复的是坐标及标签标准的一致性，不能单凭去掉外扩声称模型准确率提高。新预测相对过去默认会更紧，仍需人工确认关键结构。

窗口定位与左右文字/图标清理策略未改变；模型仍主要预测上下边界。

本轮验收：113项单元/集成测试通过；11个后端/策略模块行覆盖率85.6%（不含研究核心、前端和C#）。CPU安装版、GPU版CUDA路径及隐藏CUDA后的CPU路径均完成实际安装、预测、人工保存、协作、草稿保留和卸载验证。回退是本机隐藏CUDA模拟，不是第二台无NVIDIA电脑；验收图均为合成图。
