# 服务器部署与远程标注

> 场景：三个人不在同一地点，需要同时标注同一批数据。
> 方案：把标注工具和图片放到你的服务器上，三人用浏览器连（**他们不需要安装任何东西**）。

---

## 一、为什么这样做（而不是局域网/各装一套）

| 方案 | 可行性 | 问题 |
| --- | --- | --- |
| 局域网共享 | 只适合同一 WiFi | 三人距离远 → 不可行 |
| 每人装一套 | 可行但麻烦 | 每人要装 Python、拷 200MB 图片、数据三份难同步 |
| **服务器部署**（本方案） | ✅ | 一次部署，三人随时用；数据只有一份；**浏览器即用** |
| 反向隧道（数据留在本地） | 可行 | 需要你的电脑一直开机；服务器要额外配置转发 |

服务器实测配置：Ubuntu 24.04 / Python 3.12 / 4 核 3GB 内存 / 磁盘剩 7.5GB / **已装 Pillow**。
标注服务本身很轻（纯标准库，不用 torch、不用 GPU），3 个实例约占 100MB 内存。

---

## 二、部署（一条命令）

```bash
cd /d/ddhmodel/ddh_multidevice_v2
bash tools/deploy_server.sh ddh:你的密码
```

它做四件事：打包（图片 + 队列 + 工具）→ 上传到 `124.223.0.187:/home/ubuntu/ddh_annotate`
→ 远端解包 → 起 3 个服务（端口 8765/8766/8767，各对应 A/B/C）。

**部署后还要做一件事**：到**腾讯云控制台 → 安全组**放行 TCP `8765-8767`。
不做这一步，外面连不上（这是最常见的坑）。

自查：`curl -I http://124.223.0.187:8765` —— 返回 `401 Unauthorized` 就说明通了。

## 三、三个人怎么用

把对应的地址和账号发给同学：

```
同学 A:  http://124.223.0.187:8765    账号 ddh / 密码 你的密码
同学 B:  http://124.223.0.187:8766
同学 C:  http://124.223.0.187:8767
```

浏览器会弹一个**用户名/密码框**，输进去就能用（这就是我加的 HTTP 基本认证）。

界面操作和本地版完全一样：
- **绿线已按新口径预置**，只需微调 → **Enter 保存下一张**；
- 按 `S` 画 safe_box（裁剪线自动隐藏）；按 `1`/`0` 打 quality；
- 右侧实时显示「上边距 = N px」，落在 120–200 就说明口径没漂。

## 四、安全须知（重要）

1. **必须设密码**（`--auth`）——不加的话，任何人扫到这个端口就能看到你们的超声图；
2. 目前是 **HTTP 明文**（服务器上没有 nginx/证书）。如果你觉得不够：
   - 加一层 HTTPS：申请一个域名 + `certbot`（我可以帮你配）；
   - 或者更稳妥：改成 **SSH 隧道**——数据不出你的电脑，同学用
     `ssh -L 8765:localhost:8765 ubuntu@124.223.0.187` 后访问 `http://localhost:8765`（需要给他们各配一把 SSH key）；
3. **服务只有单向读**：工具只会读取图片、把标注写到服务器上的 `data/human_A/B/C.jsonl`，
   不会修改原图；服务器上没有原始数据的副本时也不影响使用（图片必须上传才能标注）；
4. 建议给这几个端口在安全组里**限制来源 IP**（如果同学的网络固定），或定期换密码。

## 五、收工与合并

三种办法，任选：

```bash
# 1) 在服务器上直接合并
ssh ubuntu@124.223.0.187 "cd /home/ubuntu/ddh_annotate && python3 -c \"
import json,glob
out=open('data/annotations_merged.jsonl','w',encoding='utf-8')
for f in ['data/human_A.jsonl','data/human_B.jsonl','data/human_C.jsonl']:
    for l in open(f,encoding='utf-8'):
        if l.strip(): out.write(l)
out.close()\""

# 2) 拉回本地再合并（推荐，本地有备份）
scp ubuntu@124.223.0.187:/home/ubuntu/ddh_annotate/data/human_*.jsonl data/
python tools/merge_labels.py --inputs data/human_A.jsonl data/human_B.jsonl data/human_C.jsonl --apply

# 3) 只检查不合并（看三人口径是否一致）
python tools/merge_labels.py --inputs data/human_A.jsonl data/human_B.jsonl data/human_C.jsonl
```

`merge_labels.py` 会打印**每人的"上边距中位"和标准差**——三人中位数之差超过 15px 就先别训练，先对齐口径。

## 六、常见问题

**Q：同学们需要装东西吗？**
A：不需要。只要浏览器（电脑或手机都行）。

**Q：服务挂了怎么办？**
A：重新跑一次 `bash tools/deploy_server.sh ...` 即可（会自动杀掉旧进程再起新的）。

**Q：会覆盖我的标注吗？**
A：不会。每人写自己的文件（`human_A/B/C.jsonl`），互不干扰；同一个人的同 id 记录会被覆盖（这是重做功能）。

**Q：服务器上看到图片，算不算数据外泄风险？**
A：取决于你和老师的要求。缓解措施：密码 + 安全组限制 IP + 用完即删（
`ssh ubuntu@124.223.0.187 "rm -rf /home/ubuntu/ddh_annotate/data/images"`）。
如果老师要求数据不出内网，就走第四节的 SSH 隧道方案。
