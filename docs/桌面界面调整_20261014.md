# 桌面界面调整

参考了 [Anthropic 官网](https://www.anthropic.com/) 和 [Claude Code 产品页](https://claude.com/product/claude-code) 的视觉层级：暖白底、深色文字、少量强调色，标题与操作文字分别排版。实际查看了参考页截图和浏览器字体样式，没有打包其商业字体或品牌素材。

## 应用中的调整

- 统一暖白 `#faf9f5`、暖灰侧栏和深色按钮。裁剪画布保留中性深灰，避免界面颜色干扰灰阶图像。
- 标题使用本机 `Noto Serif SC`，操作文字使用 `Segoe UI / Noto Sans SC`，路径与尺寸使用 `Cascadia Code / Consolas`。系统没有相应字体时使用中文系统字体回退。
- 启动页仅保留图片文件夹、保存位置和逐张审核/批量裁剪两个选项。
- 去掉渐变、玻璃效果、发光图标、统计卡片和宣传文案。侧栏以文件列表为主，底部保留主要操作。
- 像素坐标与审核记录说明按需展开；模型窗口提示显示为中文。
- 桌面标题栏、启动等待页和程序图标同步调整。

## 验证

64 项单元/集成回归测试通过。浏览器流程验证选择目录、四边调整、保存、可选 ZIP、自动批量和继续审核；补充了 1024×700 小窗口操作检查，以及用 Enter 展开坐标面板不会误保存的检查。

新增 Python 后端五个模块的行覆盖率合计为 80.6%（包含线程，不包含 C# 外壳和前端），记录位于 `data/desktop_build/ui_backend_coverage.json`。

实际桌面程序通过原生目录选择、单实例激活、CUDA 预测、人工审核、自动批量、压缩包另存及退出验证。使用合成图像，正式数据和生产模型未更改。另修复了 Windows 本机接口在请求体稍晚到达时，拒绝请求可能意外断开连接的问题；鉴权规则保持原有要求。
