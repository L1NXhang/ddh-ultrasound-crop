## 一、DDH 与 Graf 法（必须能空口讲 2 分钟）

### 1. 定义
- **DDH**：发育性髋关节发育不良（Developmental Dysplasia of the Hip），涵盖髋臼发育不良、半脱位、脱位，是一个**谱系**而不是单一病。
- **流行病学**：足月儿发生率约 1–3%（不稳定髋），真正需要治疗的比例更低；**女孩、臀位产、家族史、第一胎、羊水少**是高危因素。
- **筛查窗口**：出生后 6 周–6 个月是超声筛查黄金期；6 个月后股骨头骨化，X 线更可靠。

### 2. 为什么用超声
- 6 月龄前股骨头是**软骨**，X 线不显影；超声能显示软骨性髋臼、盂唇、Y 形弧（三叉软骨）。
- 无辐射、可动态、可重复。
- 缺点：**操作者依赖性强**（手法、角度、增益），这正是自动化质量控制的价值所在。

### 3. Graf 法的几何（必须能画在白板上）
```
        髂骨外缘（平直线）
             │
   骨顶线 ────┤  α
             │
   基线  ─────┴──────────
             │  β
   软骨顶线 ──┘
```

- **基线**：髂骨下缘（骨性髋臼下缘）的切线。
- **骨顶线**：髋臼骨顶的切线（从骨性髋臼顶到骨顶缘）。
- **软骨顶线**：髋臼软骨顶（盂唇方向）的切线。
- **α 角** = 基线与骨顶线夹角，反映**骨性覆盖**。正常 ≥60°；43–60° 为临界（IIa/IIb）；<43° 为异常（III/IV 方向）。
- **β 角** = 基线与软骨顶线夹角，反映**软骨覆盖**。Graf 分型里 β 用于区分 IIa/IIb 等亚型。
- **Y 形弧**：三叉软骨在切面上的投影，是判断标准切面的关键标志。
- **正常参考值**（Ulziibat/文献）：α 约 62–63°，β 约 55–56°（不同人群略有差异）。

### 4. 标准切面的判据（评委可能让你复述）
1. 髂骨呈**平直**强回声线（不是弯曲、不是斜切）；
2. **Y 形弧清晰**（三叉软骨可见）；
3. 髋臼顶与盂唇**完整显示**；
4. 股骨头**位于髋臼内**（不脱位）；
5. 无**过度旋转/倾斜**（check angle 在 ±5° 内，Lee 2021 用这个作可用性门控）。

> 一句话记忆："**直、弧、顶、头、正**。"

### 5. 常见测量失败（对应我们的边界问题）
- 髂骨不直 / 斜切 → 基线与骨顶线不可靠；
- Y 形弧不清 → 无法确定髋臼顶；
- **骨顶线画到软骨上** → α 偏大（假阴性）；
- **测量线画错/漏下缘** → 文献里明确列出的错误类型（Ulziibat 2024、Lee 2021）；
- 图像裁剪不当 → 结构缺失，直接无法测。

> **评委最想听的一句**："我们的上边界之所以关键，是因为它决定骨顶线的起点；起点错，α 角必错。"

## 二、超声物理（够用即可）

| 概念 | 一句话解释 | 和我们的关系 |
|---|---|---|
| **声阻抗** | 组织间声阻抗差越大，回声越强 | 骨/软骨界面强回声 → 上边界"亮" |
| **后方声影** | 强反射体（骨）后方声能衰减，形成暗带 | 骨影让边界"亮暗交界"，最模糊 |
| **各向异性** | 声束与组织界面不垂直时回声减弱 | 探头角度稍偏，边界强度就变 |
| **散斑（speckle）** | 相干成像的乘性噪声 | 边界呈颗粒状，肉眼和网络都难定 |
| **TGC / 增益** | 时间增益补偿，按深度放大 | 不同设备/设置 → 同一解剖亮度不同 |
| **黑边（black border）** | 扇形扫描区外的无回声区 | 我们阶段 A 用它定位成像区 |
| **动态范围** | 显示的回声强度范围 | 设备差异导致"同一张图长得不一样" |

> **一句话记忆**："上边界难，是因为它是**强回声（骨）与声影（暗）的交界**，还叠加散斑和各向异性。"

## 三、网络与损失（能画结构框图）

### 1. 整体
```
原图 → 阶段A规则 → 窗口(x0,y0,x1,y1)
                        ↓ crop + letterbox 384
                ResNet-18 (ImageNet 预训练)
                        ↓ Layer3 特征 (256ch, stride 16)
                  1×1 Conv → 64ch
                        ↓ ROIAlign(窗口) → 24×16
                  行池化 mean + max → 2×64
                        ↓ 两层 1D 卷积
                  累积 softmax → top / bottom 分布
```

### 2. 关键数字（必须记）
- **ResNet-18 感受野**（stage 末端）：**43 / 99 / 211 / 435 px**（原文 43/131/483 是错的）。
- **输出格点**：Layer3 stride 16 → 384 输入约 **24×24**；原报告写的"Layer1 2px 格点"错误，Layer1 是 **stride 4**。
- **ROIAlign 24×16**：24 行（纵向语义） × 16 列（横向上下文）。
- **参数量 11.37 M，模型 43.5 MB**。
- **单张 CPU 推理 199 ms**。

### 3. 累积 softmax（序数回归）
- 不直接回归一个标量，而是预测"边界落在第 k 个 bin 之前/之后"的累积概率。
- 好处：输出是**分布**（可给不确定性）、对离群标签更鲁棒、单调性天然满足。
- 两个输出头：`top` 和 `bottom`，各自一条累积分布。

### 4. 非对称损失（我们的创新点，必须讲清）
```
δ = 0.04（≈24 px，相对窗口高度）
δ 以内：不罚
向内（欠裁，切掉结构）：权重 w_in  = 2.0
向外（过裁，多留组织）：权重 w_out = 0.25
比例 8 : 1
```
- **为什么**：临床安全偏好是"宁可宽，不可窄"——欠裁会切掉骨顶/盂唇，直接毁掉测量；过裁只是多留组织，医生可以再修。
- **和 margin 的区别**：margin 是事后统一外扩；非对称损失是**训练时就让模型学会偏宽**，且是**有方向的**。

### 5. 训练配置
- 优化器 AdamW；backbone lr 3e-5、head lr 3e-4；wd 1e-4；cosine；80 epochs；patience 12；batch 8。
- 增强：亮度/对比度 ±10%、水平翻转 50%、高斯噪声 0.01。
- 采样：按 `leak_group` **反频率加权**，避免大组主导。

### 6. 一句话对比（被问"为什么不用 Transformer/分割"时）
> "在 862 张这个量级，**归纳偏置比容量更重要**；ResNet-18 + 序数回归已经够用，换大模型的边际收益低于补标注口径。"

## 四、统计速查（最容易被问倒的部分）

### 1. 三个检验
| 场景 | 检验 | 为什么 |
|---|---|---|
| 连续误差（像素/IoU） | **配对 Wilcoxon** | 同一批图、非正态、配对 |
| 合格/不合格（比例） | **McNemar** | 配对二分类 |
| 区间估计 | **bootstrap 5000 次** | 不依赖正态假设 |

### 2. 必须会的四个概念
- **95% CI**：反复抽样 100 次，约 95 次区间会包含真值。**不是"真值有 95% 概率在里面"**（常见口误）。
- **p 值**：假设"无差异"为真时，观察到当前或更极端结果的概率。**不是"无差异的概率"**。
- **功效（power）**：真有效应时能检出它的概率；样本量不足 → 功效低 → 容易"假阴性"。
- **MDE（最小可检出效应）**：给定 α、power、n，能可靠检出的最小差异。

### 3. 我们这组数的算法（要能报出来）
设 n=88，配对。
- 51.1%（45/88）Wilson 95% CI → **40.8%–61.3%**
- 56.8%（50/88）Wilson 95% CI → **46.4%–66.7%**
- 差值 +5.7 pp → 约 **−3.4 到 +14.8 pp**
- 该设计的 MDE 约 **9–16 pp**

> **正确表述**："在当前样本量下，无法检出 5.7 个百分点的差异。" **错误表述**："两种方法没有差异。"

### 4. 多重比较
- 我们做了多组对比（6 组配置 + 多个指标），严格来说需要 Bonferroni / FDR 校正。
- 我们**没有**做正式校正——这是 Limitation，回答时主动说。

### 5. 数据泄漏的三种形态（评委可能考你）
1. **患者级泄漏**：同一患儿多帧跨 train/test。
2. **近重复泄漏**：同一张图改亮度/裁剪后重复。
3. **预处理泄漏**：归一化统计量在全量上算，再划分。

> 我们做了第 2 种（856 组 / 7 对近重复），**没做**第 1 种（无患者 ID），第 3 种按 batch 内做，未跨集。

## 六、白板推导（可能被要求现场写）

### 推导 1：感受野
```
RF_0 = 1
每层：RF = RF_prev + (k-1) * jump_prev
      jump = jump_prev * stride
ResNet-18:
stem(7x7,s2) → RF 7,  jump 2
maxpool(3x3,s2) → RF 11, jump 4
Layer1(2个3x3,s1) → RF 43, jump 4
Layer2(2个3x3,s2) → RF 99, jump 8
Layer3(2个3x3,s2) → RF 211, jump 16
Layer4(2个3x3,s2) → RF 435, jump 32
```
> 结论：**43 / 99 / 211 / 435**；Layer3 用于我们的回归头，stride 16。

### 推导 2：为什么 8:1
```
欠裁的代价 = 结构缺失 → 无法测量 → 需要重拍（临床成本高）
过裁的代价 = 多留组织 → 医生手动修一下（成本低）
设欠裁成本 ≈ 8 × 过裁成本 → 权重比 8:1
```

### 推导 3：置信区间（Wilson 近似，口算够用）
```
p̂ ± z * sqrt(p̂(1-p̂)/n)
51.1%: 0.511 ± 1.96*sqrt(0.511*0.489/88) ≈ 0.511 ± 0.104 → [40.7%, 61.5%]
```
> 和精确 Wilson 的结果（40.8–61.3）基本一致，可以现场口算。

## 八、十条红线（说了就扣分）

1. "我们的模型可以**自动诊断** DDH" → 只能"辅助裁剪"。
2. "p=0.33，说明两种方法**没有差异**" → 只能"样本量不足"。
3. "我们做了**患者级**划分" → 只能"近重复图组隔离"。
4. "**所有**数据都来自合作医院，完全合规" → 无批件编号，别说满。
5. "我们的**准确率 95%**" → 没有这个指标，别编。
6. "上边界不准是**因为数据质量差**" → 是系统性偏高 + 标签口径。
7. "**端到端**我们也试过，差不多" → 没数据，别说。
8. "**ResNet-50** 肯定更好" → 没跑过，别说。
9. "**医生也裁不准**，所以差不多就行" → 贬低临床，必扣分。
10. "这个**已经可以进医院用**了" → 只是科研原型 + 人机协同。
