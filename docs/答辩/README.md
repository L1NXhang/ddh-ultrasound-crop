# DDH 超声裁剪项目：答辩评审与备战资料

> 对象：《DDH 超声图像智能裁剪与协作审核系统》开发说明文档（12 页 PDF）  
> 方法：逐页审阅 + 仓库代码/内部文档交叉核对 + 关键文献复核  
> 用途：明早 2 小时改稿、后续 PPT、现场答辩问答、睡前速记

## 一句话结论

这是一份**工程完成度很高、临床证据链偏弱、叙事有一条很强主线**的开发文档。它最打动评委的不是“网络多大”，而是：

> 左右边界是几何题，上下边界是语义题；  
> 检测器 97% 高分但只有 22% 边缘合格，所以我们改用规则；  
> 换 ResNet-50 贵 2.4 倍，IoU 只动 0.0034；  
> 真正的大头不是模型，是标注口径——中位误差从 89 px 降到 11–18 px。

但文档里有 **3 个必须马上改的硬伤**，否则会被专业评委当场问住：

1. **感受野算错**：ResNet-18 标准递推是 43 / 99 / 211 / 435 px，不是 43 / 131 / 483；“Layer3 第一个覆盖全图”不成立。
2. **引用错位**：Lawley 2024 是**腹部超声切面分类**，不是 DDH 超声；不能写“在 DDH 超声上”。
3. **表格/数字错位**：p=0.33 是“多尺度融合”的 McNemar，不是“标注口径”；表 6 出现“90→17.5?”；17.5 是历史 v2 中位数，11.2 是本次复现中位数。

## 三个最重要的判断

### 1. 评委不会因为“网络不够大”否定你们，会因为“证据链不完整”否定你们

文档的工程部分很强：1550 张、3 种主要界面布局、862 张同条件对照、真实 Windows 客户端、批量/复核/协作/留痕、CPU 199 ms。  
但临床 AI 评委一定会问：

- 谁定的金标准？有影像科医师吗？
- 有没有患者级划分？有没有外部医院测试？
- 88 张测试集，5.7 pp 的差异，检验功效够吗？
- 裁剪对 α/β 测量或诊断准确率到底有没有提升？

文档目前对这四个问题的回答不够。**不要等评委问，主动放在 Limitations 页**。这会把“硬伤”变成“成熟”。

### 2. 最强的创新叙事不是“我们用了 ResNet”，而是“我们把一个被忽略的前置任务拆对了”

- 左右边界：黑边/窗口几何，规则可解、零样本、可解释；
- 上下边界：软组织/骨性界面，语义模糊，必须学习；
- 网络只做“上下两条线”，不做整图分割；
- 有序输出（累积 softmax）从结构上杜绝非法框；
- 非对称损失把“宁可多留、不可切掉”写进目标函数；
- 数据侧结论：标注口径 > 网络复杂度。

这条主线比“我们做了个裁剪模型”高级得多。PPT 要按这条讲，不要按“网络结构”讲。

### 3. 最危险的不是技术，是“说过头”

以下句子在答辩现场会被追问，建议全部降级：

| 不要这样说 | 改成这样说 |
|---|---|
| 单张提速 77 倍 | 批量直出 77 倍；逐张审核 10–15 倍 |
| 三人独立标注每张 | 三人分工标注 + 同图双标子集（59 张） |
| 覆盖三种设备型号 | 三种主要界面布局，含多台设备/变体 |
| 外部验证 | 跨设备版式验证；不是外部医院验证 |
| 安全包络已验证 | 安全头存在但未训练/未校准；当前 100% 人工复核 |
| 人工修正可直接回流训练 | 经复核、去重、划分后进入下一版训练池 |
| 模型达到临床水平 | 3% 容差下与标注一致率 56%，与人工-人工 56% 持平；这是标注一致性，不是诊断准确率 |
| p=0.33 说明没有差异 | n=88 欠功效；95% CI 约 −3.4 到 +14.8 pp，不能排除有临床意义的提升 |
| Layer3 第一次覆盖全图 | Layer3 感受野 211 px，覆盖约 55% 高度；16 px 格点；Layer4 435 px、32 px 格点 |
