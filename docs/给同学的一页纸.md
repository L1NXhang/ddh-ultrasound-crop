## 二、我们在做什么

这是超声髋关节（DDH）图像，我们要标出"**应该把这张图裁成什么样**"——
模型学完之后，医生只需要看一眼确认，不用再手工裁。

界面上会显示：
- **红框**：成像区（超声画面所在的矩形）—— 一般不用动
- **绿线**：裁剪的**上边界**（已经按新口径预置好了，你只需要微调）
- **蓝线**：裁剪的**下边界**
- 右侧实时显示「上边距 = N px」，**落在 110–150 之间就是对的**（绿色）

---

## 三、每张图怎么做（5–8 秒）

1. **看绿线**：它应该切在**皮下组织层下方一点**，保留掉上面那层脂肪肌肉层；
   不对就**用鼠标拖**一下（拖到哪算对：让裁剪框里包含皮下层的大部分，但不要连大片空白也带进来）；
2. **看蓝线**：应该包住股骨头下方，一般已经对了，不动；
3. **看一眼右侧的「上边距」数字**，是不是在 110–150 之间；
4. 按 **Enter** → 自动保存并进入下一张。

### 快捷键

| 键 | 作用 |
| --- | --- |
| **Enter** | 保存并下一张（最常用） |
| 拖动绿线/蓝线 | 调整上下边界 |
| **A** | 绿线恢复成"预置位置"（拖错了想重来） |
| **↑ / ↓** | 当前线微调 1 像素（按住 Shift 是 10 像素） |
| **S** | 切到 safe_box 模式（**这次先不用**，以后再说） |
| **1 / 0** | 标 quality（**这次先不用**，以后再说） |
| **K** | 跳过这张（图像有问题时用） |

## 四、三条规矩

1. **不确定就按 A 回到预置位置**——预置位置已经是"平均口径"，别自己发明标准；
2. **每标 20 张瞄一眼右侧的「上边距」数字**，如果发现自己的数字越来越大或越来越小（比如都跑到 170 以上），说明口径漂了，**停下来问负责人**；
3. **标完的不要回头改**，需要改就重标那一张；队列会自动跳过已完成的。

## 五、常见问题

**浏览器打不开 / 一直转圈？**
先检查是不是拼错了地址和端口（三个人的端口不一样）。

**要我输密码，输了没用？**
账号是 `ddh`（小写），密码 `1433223`，注意别开启中文输入法。

**按了 Enter 没反应？**
如果绿线跑出了红框（超出成像区），工具会红字提示并拒绝保存——把绿线拖回框内即可。

**关掉浏览器会丢吗？**
不会。每次 Enter 就已经存到服务器上了。下次打开会从没标完的地方继续。
