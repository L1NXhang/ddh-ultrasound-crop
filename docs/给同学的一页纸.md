# 给组员的一页纸

## 在浏览器协作审核

1. 向负责人获取审核地址、自己的账号和密码；登录信息通过私下渠道提供，不写入公开文档。
2. 打开地址并登录。每个账号只显示分配给自己的图片。
3. 红框是完整成像窗口，绿框是最终裁剪范围。拖动绿框四边，保留关键解剖结构，排除边缘图标与文字。
4. 红框不对时按 W 调整，再按 R 重新预测。按 C 返回裁剪范围。
5. Enter 确认保存并进入下一张；K 稍后处理；P 查看成品预览；Ctrl+Z 撤销。
6. 草稿和确认结果直接保存在负责人的电脑，结束时退出登录。

详见[协作审核说明](协作审核使用说明_20261015.md)。主机必须保持运行和网络连通；外网采用加密组网或 HTTPS 代理。

## 在自己的电脑裁剪

从仓库的 [Releases](https://github.com/L1NXhang/ddh-ultrasound-crop/releases/latest) 下载 Windows CPU 安装包，安装后打开软件。选择自己的图片文件夹和保存位置，逐张审核或批量裁剪。无需安装 Python 或模型环境。

不要只复制应用目录中的 DDH裁剪工具.exe。使用便携 ZIP 时，需要完整解压并保留整个文件夹。
