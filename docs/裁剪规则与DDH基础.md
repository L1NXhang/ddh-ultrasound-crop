# 裁剪规则与 DDH 基础（新人上手）

> 用途：让新加入的同学在半小时内理解"这个项目在做什么、要标什么、怎么标"。
> **医学部分只作背景介绍，一切以老师的口径和教材为准**（本文第 4 节留了老师填写的空位）。

---

## 1 项目在做什么

用**超声髋关节截图**自动给出**上下裁剪建议**，让医生从"每张手工裁"变成"看一眼、确认或微调"。

**边界（必须记住）**：
- 本项目**不做诊断**，不判断是否存在 DDH，不给分型结论；
- 程序的输出**永远要求人工确认**（`review_required=true`），不会自动覆盖原图；
- 我们做的是"把图裁到位"这件体力活，不是给医学结论。

---

## 2 DDH 与 Graf 分型的最小背景

### 2.1 髋关节超声在看什么

婴儿髋关节超声（Graf 法）在**冠状面**上观察髋臼与股骨头的关系，核心是看：
髋臼顶发育得够不够、股骨头被覆盖得够不够。测量的是**髋臼顶的倾斜角**（α 角）等指标。

### 2.2 标准切面必须出现的结构

一张"可用于测量"的标准切面，通常要同时看到下面这些结构（缺一不可）：

| 结构 | 通俗说明 |
| --- | --- |
| 髂骨下缘/髂骨线 | 图像上方那条平直的强回声线，是测量基准 |
| 髋臼顶（骨性顶） | 髂骨下缘的骨性斜坡，α 角的来源 |
| 髋臼软骨顶/盂唇 | 骨性顶外侧的软骨与盂唇（β 角相关） |
| 股骨头 | 圆形低回声结构，位于髋臼内 |
| 髋臼内壁/三叉软骨 | 股骨头内侧与髋臼的关系 |
| 关节囊 | 股骨头外侧的包膜 |

看得见这些结构 → 才可能测量；看不到 → 这张图通常**不能**用来自动提建议。

### 2.3 Graf 主要分型（背景知识，仅用于分组统计）

| 型 | α 角（参考） | 含义（简化） |
| --- | --- | --- |
| I | α ≥ 60° | 成熟 |
| IIa / IIb | 50°–59° | 生理性不成熟 / 延迟骨化（按年龄区分） |
| IIc | 43°–49° | 髋臼顶明显变浅 |
| D | 43°–49° + 股骨头移位 | 临界脱位 |
| III | α < 43° + 股骨头向外上方移位 | 脱位 |
| IV | 同上 + 股骨头进一步移位 | 完全脱位 |

> ⚠️ 本项目**不要求**标注分型，也**不允许**从图像推断分型去填标签（方案文档明确禁止这一条）。
> 分型只用于"分组看结果"，例如我们数据里 `胡` 那个批次的 157 张自带分型（IIab 105 / IIc 7 / III-IV 45），
> 那是老师给的，不是我们推的。

### 2.4 为什么"切面是否标准"是一个独立标签（quality）

在方案里 `quality=1/0` 决定"这张图能不能给自动建议"。**这个定义必须由老师给出**，
因为它有两种可能的口径，含义完全不同：
- **口径 A（可用性）**：不是标准切面 → 不给建议（这是效率问题）；
- **口径 B（安全性）**：这张图给自动建议可能造成伤害 → 拒绝（这是安全问题）。

两种口径会让校准的门槛完全不同，**标注前必须先问清楚**。

## 3 我们要标的四个东西

| 标签 | 含义 | 怎么标 | 常见错误 |
| --- | --- | --- | --- |
| `window` | 成像窗口矩形（超声成像区的四边） | 框住成像区，**不含**右侧参数文字、深度刻度、底部进度条 | 框到黑边里；把手示意图圈进来 |
| `crop` | 你希望模型输出的裁剪范围（上边界、下边界） | 在原图坐标上给两条水平线 | 左右也裁（**不需要**，宽度永远取窗口宽度） |
| `safe_box` | **必须保留**的结构联合外接框 | 把所有"绝不能裁掉"的结构圈进去，宁大勿小 | 直接照抄 crop（文档明确禁止，代码查不出这种作弊） |
| `quality` | 这张图能不能给自动建议 | 1/0/null | 忘了标；或按"裁剪难不难"而不是按老师口径 |

**坐标系铁律**：所有坐标都是**原截图像素**（不是归一化、不是裁剪后的坐标），右/下边界不含端点。

## 4 裁剪口径（本项目的标准）

### 4.1 已确认的客观约定（从现有 1072 张人工裁切图实测得出）

| 约定 | 实测证据 |
| --- | --- |
| 裁剪宽度 = **成像窗口宽度**，左右不裁 | 1072 张裁切图的宽度与窗口宽度差 ≤12px 的比例 **100%** |
| 原图**不缩放、不旋转、不加白边** | 逐张匹配：100% 在尺度 1.0 上唯一命中 |
| 上边界落在窗口内 | 实测 top 范围 294–447（窗口 y 从 136 到 744） |
| 下边界落在窗口内 | 实测 bottom 范围 506–718 |
| 裁切高度 | 79–443 px，中位 228 px（窗口高 608 px） |

### 4.2 具体口径以《[裁切口径](裁切口径.md)》为准

上面 4.1 是从现有 1072 张标注里实测出来的**客观约定**（宽度=窗口宽、不缩放、上下边界范围）。
更细的临床判断（上边界包含什么、下边界以什么结构为准、非标准切面怎么处理）写在
**[裁切口径.md](裁切口径.md)** 里，**所有人标图前先读那一份**。

## 5 标注工具怎么用

```bat
cd /d D:\ddhmodel\ddh_multidevice_v2
.venv\Scripts\activate
python tools/annotate_app.py --manifest data/train_ready.jsonl --root data
:: 或给一批新图（没有标签，模型直接给建议）：
python tools/annotate_app.py --folder "data/images/Ⅱc+Ⅱa-b" --root . --out data/annotations_human.jsonl
```

浏览器打开 `http://127.0.0.1:8765`，界面里：

- 模型**先给建议**（红=窗口框，绿=裁剪上边界，蓝=裁剪下边界）；
- 你只需要**改不对的地方**：拖线、或按 `W` 画窗口、`S` 画 safe_box、`1`/`0` 打 quality；
- `Enter` 保存并进入下一张，`Space` 表示"完全同意模型"，`K` 跳过；
- 每张的**模型预测 vs 你的最终结果**都会被记录（`model_crop`、`human_modified`），
  这些差异既用来评估"人工修改率"，也会成为下一轮训练的标签。

## 6 红线

1. **绝不覆盖原图**；所有输出另存。
2. **不确定就留空或拒绝**，不要为了"看起来完整"编一个值（未知标签写 null 是允许的）。
3. **不许用图像内容推断患者、医院、分型**并写进标签。
4. 遇到双屏、拼图、非矩形视场、严重遮挡：**标为拒绝并备注**，不要硬标。
5. 标完的东西不要自己再改回去——每张图只标一次，改动走"重新标注"流程。

## 7 常见问题

**Q：为什么左右不用裁？**
A：方案规定最终裁剪宽度等于成像窗口宽度，模型只学上下边界。你裁左右也不会被程序使用。

**Q：窗口框要不要包含右侧那排参数文字？**
A：不要。窗口 = 承载超声回声的矩形。参数文字、深度刻度、人体示意图、进度条都在窗口外。

**Q：标错了怎么办？**
A：不要回头改老标注，直接重标那一张（工具会覆盖记录），并在《裁切口径》里记一句原因。

**Q：`safe_box` 和 `crop` 有什么区别？**
A：`crop` 是"人偏好的裁剪"，`safe_box` 是"绝不能碰的结构边界"。`crop` 永远应该包含 `safe_box`
（否则就是误裁）。程序会检查这一点并在不一致时报错。
